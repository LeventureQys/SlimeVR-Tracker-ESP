### 4.2 观感一致性（软标准，替代路径执行）

- 基准截图无法自动抓取（见 0 节），按替代路径执行：
  - **参数对照表**：`验收基准\web参数对照表.md` 已列全量参数（相机/灯光/雾/色调/网格/材质/覆盖层/模型变换/UI 配色），桌面端逐项实现且由启动测试截图与单测背书；
  - **桌面端截图**：`验收基准\desktop_demo.png`（深色主题、左视口含手+网格+覆盖层、右 390px 面板四节、青色主按钮/琥珀色条可见）；
  - **用户人工对照**：旧版 web 已归档但可运行（`archived/旧版web与HTTP服务/README.md` 有启动说明），可并排人工比对。
- 已知差异（如实记录）：
  1. 标题/工具按钮为视口内独立行（web 为绝对定位叠加层），布局等效；
  2. 抗锯齿因 Intel 驱动 + PySide6 6.10 的 MSAA FBO 缺陷设为 0（记录在 hand_view.py 注释）；
  3. 光照为 Blinn-Phong 近似（web 为 PBR），参数按对照表对齐，观感允许轻微差异。
