## 2. 运行前置

1. 构建产物：`Document/Research/手套IMU解算MVP/build-final/Release/HandSkeletonStudio.exe`（若重新构建：在该工程根执行 `cmake --build build-final --config Release`）。
2. Qt 6.8.3 运行库（本机）：启动前把 Qt bin 放到 PATH 首位，避免与系统里的 6.9.2 混用：

```powershell

$env:QT_QPA_PLATFORM = 'windows'
$env:QT_OPENGL = 'desktop'
```

3. 显卡要求：OpenGL 3.3 Core（本机已满足）。

## 3. 三种启动方式

### 3.0 双击启动（最简单，无需命令行）

发布目录：`Document\Research\手套IMU解算MVP\dist\HandSkeletonStudio\`

- `启动-真实手套COM12.bat`：直接以 COM12 串口模式启动。

### 3.1 无硬件快速体验（demo 合成源，200Hz 仿真手指动作）


## 4. 界面测试路径（手动）

1. **启动与模型**：启动后应看到左手 GLB 蒙皮手模 + 黄色骨架覆盖层 + 25 关节球；鼠标左键旋转视角、右键平移、滚轮缩放、重置视角按钮。
2. **数据源面板**：
   - 类型选 `serial`：出现**串口设备下拉框**（自动每 2 秒刷新，也可点“刷新”按钮）+ “连接”按钮；选择设备（如 `COM12 - USB Serial Port`）后点“连接”。
   - 类型选 `replay`：出现“会话目录”输入框与回放速度、暂停/逐组。
   - 类型选 `demo`：直接点“启动”。
   - 诊断面板显示 CRC、丢组、队列水位与 `fusion.dt.anomaly`（正常应为每秒每通道至多 1 条聚合信息）。
3. **校准区**：
   - **启动零偏**：真实手套连接后先平放静止约 3 秒；静止零偏会自动收敛，需要重做时点击该按钮并继续保持静止。
   - **调零（中立姿态）**：零偏稳定后，摆好你想作为“零位”的手势再点击。当前姿态会设为中心位，此后五指屈伸/张合/扭转与手腕姿态都相对这个姿势计算（诊断面板会提示“调零成功”）。六路未全部有效时会提示失败且不改变现状。
   - **磁场状态**：磁力计完成独立校准前，融合模式保持 6D、磁健康显示不可用；这是防止未校准磁场拉偏六路航向的保护行为。
   - **重置相机**：只影响视角，不改算法。
4. **六路状态**：六行分别显示手腕/拇指/食指/中指/无名指/小指的有效性、融合模式（6D/9D）、静止、磁健康与置信度。
5. **手指观测**：五指 flexion/abduction/twist 与 Estimated/Held/Recovered 状态。
6. **录制**：开始 → 暂停 → 继续 → 停止；停止后目录内含 raw.bin、metadata.json、fused_poses.jsonl、observations.jsonl、skeleton_frames.jsonl、diagnostics.jsonl。
7. **回放**：数据源切到 replay，选择录制目录，可用暂停/逐组。

## 5. 受控补验清单（真实硬件，需你操作）

以下项目决定 V2.0.0 最终验收结论，建议按顺序执行并把结果反馈给 MainAgent（或直接让我用自动化命令执行）。

### A. 静置 10 分钟漂移（先做，设备平放桌面上远离金属/电源线）

```powershell
.\build-final\Release\HandSkeletonStudio.exe --source serial --port COM12 `
  --record-dir testdata\hardware\still-10min --auto-exit-ms 600000
```

结束后把 `still-10min` 目录告知我，我分析六路抖动与漂移曲线。（提示：设备放在电脑旁会受磁干扰，尽量放远 30cm 以上。）

### B. 逐指动作矩阵（佩戴手套）

每个动作做 3-5 秒，边做边录制一段即可（我可从 jsonl 分析）：

1. 手保持不动，仅手掌绕三个轴缓慢转动（验证手指相对角不随手掌旋转）；
2. 五指依次单独屈伸（观察只有对应手指变化，不串路）；
3. 五指依次单独张合；
4. 拇指对掌动作；
5. 连续握拳-张开 5 次。

```powershell
.\build-final\Release\HandSkeletonStudio.exe --source serial --port COM12 `
  --record-dir testdata\hardware\actions --auto-exit-ms 60000
```

### C. 断连重连

运行中拔掉/重新插上手套 USB（或关闭再打开设备），观察界面不崩溃、诊断面板给出错误、重新连接后恢复数据。

### D. 30 分钟耐久

```powershell
.\build-final\Release\HandSkeletonStudio.exe --source serial --port COM12 `
  --record-dir testdata\hardware\soak-30min --auto-exit-ms 1800000
```

期间注意任务管理器内存是否持续增长；结束后我会统计队列/诊断/帧率。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| `Cannot mix incompatible Qt library` | PATH 未把 Qt 6.8.3 bin 放首位（见第 2 节） |
| 打开 COM12 失败/拒绝访问 | 设备被其他程序占用（含旧实例）；关闭占用程序或重插 USB |
| 界面黑屏/无模型 | 检查 QT_OPENGL 与显卡；换一台支持 GL3.3 的机器 |
| 诊断面板大量 `fusion.dt.anomaly` | 正常应为每秒每通道 ≤1 条聚合；若刷屏说明回归 |
| 手指方向与真实动作不符 | 安装标定尚未完成（当前默认单位四元数），记录现象即可，属预期内 |
