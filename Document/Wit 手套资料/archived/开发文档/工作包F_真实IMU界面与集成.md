# 工作包 F：真实 IMU 界面与集成

## 1. 目标与前置

在手模主窗口新增“真实单 IMU”模式，装配 BLE、协议解析和单 IMU 控制器，完成扫描、连接、手指绑定、临时校准、启停驱动、实时数据与错误反馈。

- 设计依据：`document/单蓝牙IMU指尖联动设计.md`。
- 依赖前置：工作包 E 的 `handdemo_imu` 和 `SingleImuFingerController` 已可链接。
- 需保留：手动关节和六路 IMU 模拟模式及现有 smoke 路径。

## 2. 修改范围

- 修改 `src/ui/main_window.h/.cpp`。
- 必要时修改 `src/app/main.cpp` 完成对象装配。
- 修改根 `CMakeLists.txt` 的应用链接项。
- 新增 UI 状态机或集成测试。
- 更新 `README.md` 的真实设备使用和限制说明。

不得在 UI 槽函数实现姿态数学，不得自动启用驱动，不得把演示数据标记成真实设备数据。

## 3. 交互契约

严格按设计文档第 6 节实现控件启用规则。主流程为：

`扫描 -> 选择设备 -> 连接 -> 选择手指 -> 收到有效姿态 -> 临时校准 -> 启用驱动`。

以下操作必须停止驱动并清除校准：断开、BLE 异常断开、换手指、重置姿态、数据超时。重新收到数据不得自动恢复驱动，必须由用户重新校准并启用。

## 4. 状态显示契约

- 连接状态来自 `WitBleManager::stateChanged`。
- 实时数值来自 `WitProtocolParser::dataUpdated`。
- 映射诊断来自 `SingleImuMappingOutput`。
- 错误必须包含面向用户的中文摘要；协议、UUID、时间戳和状态转换详情可以放入技术详情或日志。
- 界面持续显示工程近似和单 IMU 无法恢复真实关节角的提示。

## 5. 验收标准

- 初始状态下校准与驱动不可用。
- 连接成功并收到有效帧后，选择手指可执行临时校准。
- 校准成功后首帧不导致模型跳动。
- 启用驱动后只有所选手指响应，其他手指保持绑定姿态。
- UI 显示加速度、角速度、欧拉角、帧数、更新时间、电量、温度和版本。
- 原手动模式、六路模拟模式和 smoke test 继续通过。
- 无硬件时应用可启动并显示可恢复状态，不因扫描失败崩溃。
- 真实设备路径按新版验收文档保留操作记录和截图。
