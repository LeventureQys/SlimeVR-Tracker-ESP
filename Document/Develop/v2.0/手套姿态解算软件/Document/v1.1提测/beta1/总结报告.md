## 4. 技术要点

### 4.1 渲染修复

- **z-fight**：overlay（骨骼点/线）绘制前 `glDisable(GL_DEPTH_TEST)`，绘制后恢复，避免与 mesh 深度冲突产生彩色闪烁。
- **Specular 高光**：在 GLSL fragment shader 中增加 Blinn-Phong specular 项（half-vector，指数 32，强度 0.3），使模型表面有光泽反射。

### 4.2 UI 布局

- 右侧 dock `setMinimumWidth(340)` + `QScrollArea` 包裹，解决小窗口下控件截断。
- 左侧 dock `setMinimumWidth(200)`，骨骼树不再被挤压。
- 状态栏标签设置最小宽度，文字不再截断。

### 4.3 录制功能

- `DataRecorder` 类：状态机（Idle/Recording/Paused），CSV 文件输出（16 列），带时间戳文件夹。
- UI 集成：在"真实单 IMU"面板底部添加录制按钮组（开始/暂停/停止）+ 时间标签（mm:ss）。
- 数据连接：`protocolParser_->dataUpdated` 信号同时驱动 UI 更新和数据录制。
