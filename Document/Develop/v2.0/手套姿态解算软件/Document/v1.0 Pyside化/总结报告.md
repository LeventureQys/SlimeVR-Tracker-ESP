## 3. 技术要点与关键决策

1. **PySide6 版本锁定 6.10.3**：6.11.1 已移除 Qt3D Python 绑定（实测模块为空壳）；6.10.3 为 cp39-abi3，Python 3.9+ 可用（本机 3.14.4 实测）。
2. **渲染器与 PySide6 6.10 绑定缺陷的博弈**（全部实测定位，非猜测）：
   - Qt3D 无法导入 .glb（gltf 导入器只注册 `gltf` 扩展名、assimp 导入器格式表不含 glb）、glTF 导入器不解析 skin → 否决 Qt3D；
   - QtOpenGL 绑定缺 GL_* 常量、glGetShaderiv/glGetProgramiv 出参不写入、glVertexAttribPointer 全形态报错、glDrawElements 报错、无 VAO 函数、Intel 驱动下 MSAA FBO 创建失败 → 以"兼容 profile（免 VAO）+ 双函数对象混合 + 内置常量表 + wglGetProcAddress/opengl32 导出表 ctypes 兜底 + QOpenGLBuffer 替代 glBufferData + samples=0"组合规避；
   - QOpenGLWidget 在多层布局中因无 stretch 因子获得 0 高度 → FBO "missing attachment" → 视口加 stretch(1) 修复。
3. **蒙皮正确性三重证明**：glTF 规范式 + bind 姿态逐顶点不变性单测（硬门禁）+ three.js r160 同资产实跑逐元素交叉验证（1.06e-5）。
4. **模拟数据源**：按真实 AA55 协议合成字节流（确定性脚本），无硬件也能演示与验收；走与真实串口完全相同的解析路径。
5. **验收证据自动化**：`--screenshot`（widget.grab + GL framebuffer 合成，规避 DWM 全黑限制）与 QTest 交互冒烟（17 项功能检查）。
