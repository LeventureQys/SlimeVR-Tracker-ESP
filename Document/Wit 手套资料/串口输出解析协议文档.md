# 串口输出解析协议文档

## 1. 适用范围

本文档适用于当前工程 `Template` 中的默认串口输出协议。
当前工程默认输出模式为：

- **输出口**：`USART0`
- **波特率**：`921600`
- **数据格式**：`8N1`
- **输出类型**：**二进制原始帧**
- **输出频率**：约 **200Hz**

------

## 2. 数据流说明

串口输出为**连续字节流**，不是一包一包独立发送。
因此抓包时，数据**可能从任意位置开始**，不一定第一个字节就是帧头。

解析时应通过固定帧头：

```
AA 55
```

来同步一帧数据。

------

## 3. 单帧格式

每一帧固定长度为 **25 字节**。

### 帧结构

```
AA 55 ADDR SEQ 12 AXH AXL AYH AYL AZH AZL GXH GXL GYH GYL GZH GZL MXH MXL MYH MYL MZH MZL CRCL CRCH
```

------

## 4. 字段定义

| 偏移  | 长度 | 字段名  | 说明                                |
| ----- | ---- | ------- | ----------------------------------- |
| 0     | 1    | Header0 | 固定 `0xAA`                         |
| 1     | 1    | Header1 | 固定 `0x55`                         |
| 2     | 1    | ADDR    | 设备地址                            |
| 3     | 1    | SEQ     | 采样序号                            |
| 4     | 1    | LEN     | 固定 `0x12`，表示后续数据区 18 字节 |
| 5~6   | 2    | AX      | 加速度 X                            |
| 7~8   | 2    | AY      | 加速度 Y                            |
| 9~10  | 2    | AZ      | 加速度 Z                            |
| 11~12 | 2    | GX      | 陀螺仪 X                            |
| 13~14 | 2    | GY      | 陀螺仪 Y                            |
| 15~16 | 2    | GZ      | 陀螺仪 Z                            |
| 17~18 | 2    | MX      | 磁力计 X                            |
| 19~20 | 2    | MY      | 磁力计 Y                            |
| 21~22 | 2    | MZ      | 磁力计 Z                            |
| 23    | 1    | CRC_L   | CRC16 低字节                        |
| 24    | 1    | CRC_H   | CRC16 高字节                        |

------

## 5. 地址定义

| 地址值 | 传感器位置  |
| ------ | ----------- |
| `0x50` | wrist 手腕  |
| `0x51` | thumb 拇指  |
| `0x52` | index 食指  |
| `0x53` | middle 中指 |
| `0x54` | ring 无名指 |
| `0x55` | pinky 小指  |

------

## 6. 数据类型与字节序

### 6.1 9轴数据类型

`AX~MZ` 均为：

- **int16**
- **有符号整数**
- **高字节在前，低字节在后**（Big-Endian）

例如：

```
02 76 -> 0x0276 -> 630
FF F9 -> 0xFFF9 -> -7
```

------

## 7. 一组数据的定义

同一个 `SEQ` 的多帧属于**同一次采样**。

正常情况下，同一个 `SEQ` 会包含 6 个地址：

```
50 51 52 53 54 55
```

即：

- 手腕
- 拇指
- 食指
- 中指
- 无名指
- 小指

所以在上位机中建议按：

- **先按帧头切帧**
- **再按 SEQ 分组**
- **再按 ADDR 区分传感器**

------

## 8. CRC 校验

### 8.1 CRC 算法

使用：

- **Modbus CRC16**
- 初值：`0xFFFF`
- 多项式：`0xA001`

### 8.2 校验范围

CRC 计算范围为：

- **本帧前 23 字节**
- 即从 `AA` 到 `MZL`

### 8.3 存储顺序

CRC 在帧尾按：

- **低字节在前**
- **高字节在后**

存储，即：

```
CRC_L CRC_H
```

------

## 9. 解析流程建议

### 9.1 推荐解析步骤

1. 在连续字节流中查找帧头 `AA 55`
2. 从帧头开始读取固定 **25 字节**
3. 检查第 5 字节是否为 `0x12`
4. 校验 CRC16
5. 解析 9 个 `int16` 数据
6. 根据 `ADDR` 标识传感器
7. 根据 `SEQ` 归并为同一时刻的一组数据

------

## 10. 示例

### 原始帧

```
AA 55 50 E1 12 02 76 04 F4 05 B7 FF FE FF F9 FF F5 00 00 00 03 00 08 CD 75
```

### 解析结果

- 帧头：`AA 55`
- 地址：`0x50` → 手腕
- 序号：`0xE1`
- 长度：`0x12`

9轴数据：

- `ax = 0x0276 = 630`
- `ay = 0x04F4 = 1268`
- `az = 0x05B7 = 1463`
- `gx = 0xFFFE = -2`
- `gy = 0xFFF9 = -7`
- `gz = 0xFFF5 = -11`
- `mx = 0x0000 = 0`
- `my = 0x0003 = 3`
- `mz = 0x0008 = 8`
- CRC：`CD 75`

------

## 11. 注意事项

### 11.1 抓包开头不一定有 `AA`

因为串口输出是连续流，抓包可能从中间开始。
所以看到类似：

```
55 53 E0 12 ...
```

并不代表协议没有帧头，只是抓取位置不在帧起点。

------

### 11.2 数据可能存在不完整帧

如果复制的数据在结尾处截断，例如只剩一半帧，解析程序应直接丢弃该残帧。

------

### 11.3 某些节点可能输出全 0 数据

如果某个从节点在该采样窗口未收到有效响应，工程会输出一个对应地址的**零数据帧**，数据区 18 字节全为 0，但格式和 CRC 仍然有效。

------

## 12. 协议总结

当前工程串口输出协议可概括为：

> **帧头 `AA55` + 设备地址 + 序号 + 9轴原始数据 + CRC16**

其中 9轴顺序固定为：

```
ax, ay, az, gx, gy, gz, mx, my, mz
```
