### 5.3 真实串口启动 ✅（环境解除后实测）

COM12 于 2026-08-20 13:38 后恢复可访问（用户侧调整），MainAgent 实测：

- `hardware_baseline_capture --port COM12 --duration 8`：输入 238080 字节，9522 有效帧，**CRC 错误 0**，未知地址 0，**1586 完整组（≈198.3 组/s，符合 200Hz 目标）**。数据集：`testdata/hardware/baseline-20260820-a/`（raw.bin SHA256=3616c788…）。
- 产品真实串口运行：`HandSkeletonStudio.exe --source serial --port COM12 --screenshot SubStage6_serial_real.png --auto-exit-ms 12000` → **exit 0**，截图 60970 字节。
- 产品真实录制：`--source serial --record-dir testdata/hardware/serial-session-real3 --auto-exit-ms 15000` → exit 0；2963 组/15s（≈197.5 组/s），raw.bin 444416 字节，fused/observations/skeleton 各 2963 行。
- 产品真实回放：`--source replay --replay testdata/hardware/serial-session-real` → exit 0，截图 74506 字节。

**实测中修复的真实缺陷**：串口批量到达使组时间戳按 ~131ms 分桶，融合层 dt 逐组回退并刷爆诊断文件（20 秒 23420 条）。已修复为聚合诊断（每秒每通道一条 `fusion.dt.anomaly`，含零dt组/回退组计数），15 秒会话诊断从 23420 行降至 84 行；`test_fusion` 新增 `dtZeroBatchAggregatesAndFallbackRateLimits` 锁定行为，全量 ctest 18/18 保持通过。有效融合 dt 使用标称 5ms，与实测组周期 5.04ms 偏差 <1%，数值上无系统性误差。

**仍待用户侧补验**：受控静置（当前随手采集的 15s 样本航向变化 ~39°，但设备摆放位置、磁环境与动作均未受控，不能作为漂移结论）、逐指动作矩阵、10 分钟静置漂移、30 分钟耐久，以及量程/轴向/安装方向的硬件参数确认（metadata 仍为 unknown）。

## 9. 失败项、风险与豁免

1. **真实硬件验收豁免（需用户批准）**：COM12 真实 FTDI 设备被 DSH 沙箱拒绝访问，六路实时/动作/精度/耐久验收无法在本环境执行。申请将其记录为经批准的环境阻塞，并约定用户侧补验方式（见第 10 节问题清单）。
2. **30 分钟耐久与性能分位数**：未执行，列为用户侧补验项。
3. **UI 遗留接线**（SubStage 6 报告 §9）：回放速度控件未接 `setBytesPerSecond`；原始参数/中立/安装校准按钮无完整持久化对话框；`--config` 的量程/安装参数尚未完整映射到 CalibrationPipeline。均为功能完整性缺口，不影响合成闭环，但真实硬件验收前必须补齐。
4. **算法边界**（SubStage 3 报告 §7）：磁力计增益默认 1.0 µT/LSB 为未确认占位；磁健康仅按模长判异常；硬/软铁为轴向缩放简化法。真实精度结论需真实数据复核。
5. **Assimp 未纳入**：自包含 GLB 解析器已通过契约与 bind 不变性测试；联网环境可再验 Assimp 路径（非阻塞）。
6. **git tag**：`Document/` 整体未被 git 跟踪，直接打 tag 会指向不含 V2.0 代码的旧提交。需用户决定是否 `git add/commit` 后再打 `v2.0.0` tag（见第 10 节问题清单）。
