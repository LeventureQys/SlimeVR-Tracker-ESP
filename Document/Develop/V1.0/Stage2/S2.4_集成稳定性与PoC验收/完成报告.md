## 4. 关键行为

- 设置默认禁用；启用后连接即注册六路、每秒重发，Server 重启自动重连重注册；
- 关闭窗口停止网络定时器并释放 socket；
- 手侧切换重新握手并携带新 tracker type；安装旋转保存后即时生效且不重置融合；
- 网络模块不侵入串口/解析/融合，禁用即完整回退原工具行为；
- 探针支持 `--host/--port/--side/--rate/--serial/--quit-after-ms`，用于真实 Server 验证。
