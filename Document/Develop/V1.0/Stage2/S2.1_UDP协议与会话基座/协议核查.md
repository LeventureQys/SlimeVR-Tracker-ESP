# SlimeVR Raw UDP 协议事实核查

核查基线：SlimeVR Server 稳定版 `v20.1.0`（提交 `81a46c2`），Server `main` 与稳定版在本文涉及部分一致；ESP 固件 `main` 提交 `9ae0df5`，协议修订 22。本文件为 S2.1 客户端实现的协议依据。

## 1. 通用包头

- 普通包：4 字节大端 packet type + 8 字节大端 packet number + body；
- 特殊格式例外：发现响应（64 字节）与 SensorInfo ACK（6 字节，无包号）。

## 2. 端口与会话

- Server 默认监听 UDP `6969`；握手目标默认 `6969`；
- 客户端本地端口不属于协议身份，应使用临时端口（同机 Server 已占用 6969 时必须如此）；
- Server 按源地址建立 connection 并回包。

## 3. 握手（type 3）

- 布局与固件 `sendTrackerDiscovery()` 一致（board/imu/mcu/3×旧IMU-info/protocol/firmware/MAC/trackerType/vendor…）；
- Server 只解析到 MAC；未知 board/imu/mcu 映射 UNKNOWN，不拒绝；MAC 全零变 null；
- MAC 后的 trackerType 与 vendor/product/update 字段被 Server 忽略（左右手由 SensorInfo position 决定）。

## 4. 发现响应

- 固定 64 字节：`03` + `"Hey OVR =D 5"` + 51 字节零；有效前缀 13 字节。

## 5. 心跳 / 超时 / PingPong

- Server 每约 `500 ms` 向每个连接发 type 1 心跳；tracker 回 type 0；
- Server 侧：`1000 ms` 未收到 tracker 任何有效包则标 timed out；
- 客户端侧：固件以 `3000 ms` 未收到 Server 非握手包判超时（本实现沿用）；
- Server 每约 `500 ms` 发 PingPong（type 10 + pingId u32）；tracker 必须原样回显，缺失不影响连接。

## 6. SensorInfo（type 15）

- 官方 ESP 完整 body 15 字节（含两个 TPS float），总长 27；Server 实际只消费前 7 字段（至 sensorDataType），TPS 不读取；
- 本实现发送 8 字节 body（总长 20），字段缺省与 Server 一致，完全可接受；
- Server 收到后回 6 字节 ACK：`BE32 type=15 + sensorId u8 + state u8`，无包号；
- 官方 ESP 在未 ACK 或状态变化时重发；本实现改为连接后立即 + 每秒重发（决策记录，见 S2.2 问题清单）。

## 7. RotationData（type 17）

- body 19 字节：sensorId/dataType/x/y/z/w（各 BE f32）/accuracy；总长 31；
- dataType `1`=normal、`2`=correction；accuracy 为校准精度字节，Server 对 normal 暂不使用；
- Server 不归一化：NaN/全零替换 identity，其余原样；客户端必须自行保证单位四元数（本实现已保证）。

## 8. FeatureFlags（type 22）

- Server 不主动发；tracker 请求后 Server 回复 flags（稳定版 bit0=bundle、bit1=compact bundle）；
- 不请求/不发送不影响握手、SensorInfo 与 RotationData；未交换 flags 时使用非 bundle 单包（本实现路线）。

## 9. 节点与手侧

- 握手 trackerType（0/1/2）当前被 Server 忽略；
- 手/手指节点完全由 SensorInfo `sensorPosition` 决定：左手 `17(HAND)/23/26/29/32/35`，右手 `18/38/41/44/47/50`；
- `trackerDataType`（0=rotation）决定数据类型。

## 10. 其他

- packet number：已连接 tracker 必须单调递增（Server 校验 `isNextPacket`）；握手包号固定 0；
- 配置 ACK（type 25→24）仅当宣告 SENSOR_CONFIG 能力时才需要——本实现不发送 flags，不会触发；
- Serial（type 11）为可选遥测，非注册/保活要求。

## 11. 对实现的影响评估

| 核查项 | 本实现行为 | 结论 |
| --- | --- | --- |
| 端口/绑定 | 目标 6969，本地临时端口 | 一致 |
| 发现响应 | 前缀 13 字节校验（接受 64 字节） | 一致 |
| 心跳/PingPong | 回 type 0 / 原样回显 | 一致 |
| SensorInfo ACK | 作为普通包刷新超时并忽略 | 安全，无需改动 |
| 超时 | 客户端 3000 ms；心跳 500 ms 保持连接活跃 | 一致 |
| 左右手 | 由 position 枚举决定 | 一致 |
| FeatureFlags | 不交换，非 bundle 单包 | 一致 |
