# V2.0 阶段 0：基线冻结与 C++ 统一路线

## 1. 结论

V2.0 主实现统一使用 C++/Qt。

主宿主工程确定为：

```text
Document/Research/手套IMU解算MVP/
```

该工程负责：

- 六路原始 IMU 串口输入；
- 原始协议解析和同 sequence 分组；
- 六路姿态融合；
- 后续掌指相对姿态和骨骼解算；
- 后续 FBX 骨架与蒙皮显示。

以下 C++ 模块作为骨骼算法来源复用：

```text
Document/Wit 手套资料/archived/src/motion/
```

PySide6 手套软件保留为显示效果、25 关节语义和录制交互参考，不再作为 V2.0 主实现语言和主运行时。

SlimeVR UDP 网络模块保留在现有工程中以避免破坏 V1.0，但不进入 V2.0 骨骼主链路。

## 6. 尚未关闭的真实硬件项

以下事项必须通过真实手套或录制数据关闭：

1. 六路原始协议与真实主控输出完全一致；
2. 加速度、陀螺仪和磁力计实际量程；
3. 六颗 PCB 的真实轴方向；
4. 六颗 IMU 的物理安装旋转；
5. 手指 IMU 的实际安装骨段；
6. 真实 200 Hz 完整组率；
7. 真实静置漂移和磁场干扰表现；
8. 左右手物理装配差异。

演示源只能验证软件链路，不能关闭上述项目。
