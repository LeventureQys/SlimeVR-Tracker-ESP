# V1.0-S2.4：集成稳定性与 PoC 验收需求

- 所属阶段：V1.0 阶段 2
- 前置依赖：`S2.1`、`S2.2`、`S2.3` 全部验收通过
- 版本目标：完成 Qt 集成、故障恢复和阶段 2 正式验收

## 1. 目标

1. 将 SlimeVR 输出完整集成到现有 Qt 工具；
2. 提供连接与六路发送诊断；
3. 验证串口、融合、UI 和网络并行；
4. 验证 Server 重启、网络异常和配置异常恢复；
5. 形成阶段 2 PoC 验收资料。

## 2. 功能需求

### FR-1 UI

设置包括启用、发现模式、地址、端口、手侧、`50–100 Hz` 发送率和六路安装旋转入口。状态显示会话、Server、手侧、注册数、总/每路发送率、错误/拒绝/重连计数和最近收发时间。沿用低频 UI timer，禁止逐包刷新。

### FR-2 生命周期

启动时读取配置；无串口时不发送伪造姿态；切换真实/演示源时清理旧姿态年龄；禁用时停止发送和重连；关闭窗口释放 timer、signal 和 socket；重复开关必须幂等。

### FR-3 恢复

覆盖 Server 晚启动、Server 重启、地址不可达后恢复、socket 错误、串口断开恢复、姿态超时恢复、旧/坏配置和手侧切换。恢复后只发送最新姿态，不重放历史。

### FR-4 资源有界

姿态仅保留最新快照；无无界发送队列；重连任务、timer 和 signal 不重复累积；日志历史有上限；30 分钟内内存、句柄和 timer 数不持续增长。

## 3. 验收测试

- 原有五类自动测试继续通过；
- 新增 UDP、会话、映射、节流、坐标和设置测试通过；
- 自动测试使用回环动态端口和临时 `QSettings`；
- 真实 Server 覆盖先后启动、重启、六路动作、左右切换、禁用、串口断开和无效姿态；
- 真实六 IMU、约 200 Hz 融合、75 Hz 网络连续运行 30 分钟。

30 分钟记录开始/结束时间、六路输入/发送率、CRC/缺组/拒绝、握手/重连/发送错误、内存和句柄、在线状态，以及 NaN、崩溃、卡死和 UI 阻塞。

## 4. 交付物

- 完整 UI 和诊断；
- 配置迁移和故障恢复；
- 自动化回归结果；
- 真实 Server、坐标和 30 分钟稳定性记录；
- 用户操作及排障说明；
- 问题清单和阶段 2 完成报告。

## 5. 最终验收标准

1. Server 识别一个正确手侧设备和六路传感器；
2. 六路无串路且方向正确；
3. 左右切换和重启配置一致；
4. Server 重启自动恢复；
5. 发送率可配置且不积压；
6. 30 分钟无崩溃、异常增长和不可恢复断连；
7. 原有功能无回归；
8. 自动与真实验收资料完整；
9. 未实施阶段 3 及后续算法优化。
