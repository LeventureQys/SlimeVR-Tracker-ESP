# 架构说明（当前主线）

本文是 HandSkeletonStudio 当前实现的精简架构说明；权威版本为 `Document/Update/v2.0.0 - 六路IMU手部骨骼闭环/设计文档.md`。

## 数据链路

```text
串口/回放原始字节 (AA 55 25字节帧, 921600/8N1)
  → IDataSource (bytesReady)
  → FrameStreamParser (CRC/长度/重同步, 只发合法帧)
  → SequenceGrouper (同 sequence 六路分组, pending≤8, 完整组才继续)
  → CalibrationPipeline (量程/轴映射/零偏/磁修正 → CalibratedImuSample)
  → FusionBank (六路 Madgwick/VQF, dt 回退保护, 磁健康状态机, PoseGuard)
  → HandObservationSolver (掌指相对/安装修正/方向分解/调零)
  → KinematicSkeleton (虚拟层级 FK/限位/耦合/缺帧状态)
  → HandSkeletonFrame → HandRenderWidget (GLB GPU 蒙皮 + 骨架覆盖层)
```

- 三种数据源（serial/replay/demo）从 `bytesReady` 起走完全相同的链路。
- 录制：raw.bin（字节 1:1）+ metadata + fused/observations/skeleton/diagnostics jsonl，有界队列，raw 最高优先。
- 回放：同一链路 + 哈希校验 + 原速/暂停/逐组，确定性已验证。

## 线程模型

- GUI 线程：MainWindow / HandRenderWidget / 表格与诊断。
- 算法 worker 线程：数据源、解析、分组、校准、融合、观测、骨骼、录制 flush。
- 跨线程只传不可变值对象（queued signal）；模型用 `shared_ptr<const RiggedModel>` 共享。
- 退出顺序：停数据源 → 断信号 → 停录制 flush → worker quit/wait → 销毁 UI/GL。

## 关键冻结契约

- 四元数 Hamilton wxyz；矩阵 QMatrix4x4；时间 qint64 单调纳秒。
- `qRelative = inverse(qPalm) * qFinger`；`qCorrected = qMount * qRelative * inverse(qMount)`。
- `globalMatrix = displayRoot × bindWorld × accumulatedDelta`；`skinMatrix = globalMatrix × inverseBind`；`rootTransform` 仅记录值。
- 目标 GLB 的 25 关节在资产节点树中平铺：蒙皮 palette（skin.joints 顺序）与虚拟解剖层级解耦，按唯一骨名映射。
- 调零（中立姿态）：记录当前六路姿态为参考，其后观测相对参考计算（`HandObservationSolver::setNeutral`）。
- 串口批量到达 → 组时间戳按 ~131ms 分桶：融合 dt 使用标称 5ms（与实测组周期 5.04ms 偏差 <1%），异常聚合为每秒每通道一条 `fusion.dt.anomaly` 诊断。

## 模块与目标

| 库 | 内容 |
| --- | --- |
| handstudio_core | 契约/配置/校准/融合（含 vendor VQF 与遗留 Madgwick 数学核心） |
| handstudio_io | 协议/输入/录制回放 |
| handstudio_hand / handstudio_skeleton | 手部观测 / 骨骼求解 |
| handstudio_model / handstudio_render | GLB 导入 / OpenGL 渲染 |
| handstudio_app | UI、运行时编排、demo 源 |
| HandSkeletonStudio.exe | 产品（不链接 six_imu_core / six_imu_network） |
