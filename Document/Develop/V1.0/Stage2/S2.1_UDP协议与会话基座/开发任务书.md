### 4.2 协议

```cpp
namespace SlimeVrProtocol {
enum class SendPacketType : quint32 { HeartBeat = 0, Handshake = 3 };
enum class ReceivePacketType : quint32 { HeartBeat = 1, Handshake = 3, PingPong = 10 };

struct HandshakeIdentity {
    quint32 board;
    quint32 primarySensorType;
    quint32 mcu;
    quint32 protocolVersion;
    QByteArray firmwareVersion;
    std::array<quint8, 6> deviceId;
    quint8 trackerType;
    QByteArray vendorName;
    QByteArray vendorUrl;
    QByteArray productName;
    QByteArray updateAddress;
    QByteArray updateName;
};

QByteArray encodeHandshake(const HandshakeIdentity &);
QByteArray encodeHeartbeat(quint64 packetNumber);
bool isDiscoveryResponse(const QByteArray &datagram);
std::optional<quint32> decodePacketType(const QByteArray &datagram);
}
```

所有编码函数显式 append 大端字段，不使用 packed struct、reinterpret_cast 或主机字节序复制。

### 4.3 客户端

```cpp

struct SlimeVrNetworkStatistics {
```

## 6. 必测行为

- 握手首 12 字节是 `00 00 00 03 00 00 00 00 00 00 00 00`；
- 所有 32/64 位整数大端；
- 长字符串超过 255 字节时编码失败，不截断；
- 发现响应不足 13 字节时安全拒绝；
- 非目标来源普通包不刷新 last-valid-receive；
- Server HeartBeat 类型 `1` 触发客户端 HeartBeat 类型 `0`；
- PingPong 保持原始数据报内容；
- 超时后停止 Connected，并按退避重新握手；
- stop 后无 timer 和发包；
- fake server 与客户端析构后端口可重新绑定。
