## 2. 背景与目标

本工程是独立 Qt 6 Widgets 桌面程序，用于通过串口实时接收手套六个 IMU 的九轴原始数据。程序必须完成连续字节流同步、CRC16 校验、同 `SEQ` 六路分组、原始数据与链路诊断显示，并对手腕、拇指、食指、中指、无名指和小指分别执行 Madgwick 姿态融合。

首版姿态主输出为单位四元数，辅助输出为 ZYX 欧拉角；磁场有效时使用九轴融合，磁场无效时自动退化为六轴融合。程序提供六路零位标定、持久化姿态参数对话框、演示模式、单元测试与启动测试。

本版本不进行人体骨骼约束、MCP/PIP/DIP 关节角求解、三维手模渲染、数据录制、网络输出或设备配置写入。

## 8. 协议解析契约

### 8.1 CRC16

```cpp
quint16 crc16Modbus(QByteArrayView bytes);
```

- 初值 `0xFFFF`；
- 多项式 `0xA001`；
- 计算范围为候选帧前 23 字节；
- 帧尾期望值为 `frame[23] | frame[24] << 8`。

### 8.2 `FrameStreamParser`

```cpp
class FrameStreamParser final : public QObject {
    Q_OBJECT
public:
    explicit FrameStreamParser(QObject *parent = nullptr);
    void appendBytes(const QByteArray &bytes, qint64 monotonicNs);
    void reset();
    ParserStatistics statistics() const;
signals:
    void frameParsed(const ImuFrame &frame);
    void statisticsChanged(const ParserStatistics &statistics);
};
```

解析过程：

1. 空输入直接返回；
2. 追加输入并增加 `inputBytes`；
3. 查找 `AA 55`；
4. 未找到时仅保留末尾单字节 `AA`，其余计入 `discardedBytes`；
5. 帧头前噪声删除并计入丢弃；
6. 不足 25 字节保留等待；
7. 候选帧增加 `headerCandidates`；
8. `frame[4] != 0x12` 时增加 `invalidLength`，只丢弃第一个 `AA` 后重新同步；
9. CRC 错误时增加 `invalidCrc`，只丢弃第一个 `AA` 后重新同步；
10. 有效帧从缓存删除并按偏移解析九个大端 `qint16`；
11. 增加 `validFrames`；未知地址另增 `unknownAddressFrames`；
12. 发出 `frameParsed`，继续处理剩余缓存。

解析器不抛异常，不弹对话框，不因错误帧清空整个缓存。

## 9. 同步分组契约

### 9.1 `SequenceGrouper`

```cpp
class SequenceGrouper final : public QObject {
    Q_OBJECT
public:
    explicit SequenceGrouper(int maxPending = 8, QObject *parent = nullptr);
    void addFrame(const ImuFrame &frame);
    void reset();
    GroupStatistics statistics() const;
signals:
    void completeGroupReady(const ImuSampleGroup &group);
    void partialGroupDropped(const ImuSampleGroup &group);
    void statisticsChanged(const GroupStatistics &statistics);
};
```

行为：

- 未知地址帧直接忽略，不进入 pending；
- 按 `sequence` 创建或查找组；
- 同一组同一地址重复时增加 `duplicateFrames` 并以最新帧覆盖；
- 每个已知地址有效帧增加对应 `sensorFrameCounts`；
- 集齐六路后立即从 pending 删除，增加 `completeGroups` 并发出 `completeGroupReady`；
- pending 使用到达次序，不以序号整数比较新旧，正确支持回绕；
- pending 数量超过 `maxPending` 时淘汰最早到达组，增加 `partialGroups` 并发出 `partialGroupDropped`；
- `reset()` 清空 pending 与统计，不发出淘汰信号。

## 11. 姿态融合契约

### 11.1 坐标、单位与输出

- 六路传感器轴向一致，不进行每路轴交换；
- 输入加速度单位为 g；
- 输入角速度先从 °/s 转为 rad/s；
- 输入磁场为 `raw / magnetometerDivisor` 的参考值；
- 四元数表示传感器局部坐标到世界坐标的右手旋转；
- 存储顺序为 `QQuaternion(scalar, x, y, z)`；
- 每次有效更新后归一化；模长非有限或小于 `1e-12` 时拒绝结果并保留上一有效状态；
- 欧拉角只用于显示，采用内禀 ZYX：Roll(X)、Pitch(Y)、Yaw(Z)。

### 11.2 `MadgwickFilter`

```cpp
enum class FusionMode {
    Invalid,
    SixAxis,
    NineAxis
};

struct Vector3d {
    double x = 0.0;
    double y = 0.0;
    double z = 0.0;
};

class MadgwickFilter final {
public:
    explicit MadgwickFilter(double beta = 0.10);
    void reset();
    void setBeta(double beta);
    bool update(const Vector3d &gyroRadPerSecond,
                const Vector3d &accelerationG,
                const std::optional<Vector3d> &magnetic,
                double dtSeconds);
    QQuaternion quaternion() const;
    FusionMode mode() const;
};
```

行为：

- 初始四元数为单位四元数；模式 `Invalid`；
- `dt` 非有限、`<= 0` 或 `> 0.1` 时返回 false；
- 陀螺仪或加速度任一分量非有限时返回 false；
- 加速度模长小于 `1e-12` 时返回 false；
- 磁场存在且向量有限、模长有效时执行标准 Madgwick MARG 九轴更新，模式 `NineAxis`；
- 无磁场时执行标准 Madgwick IMU 六轴更新，模式 `SixAxis`；
- 梯度模长接近零时跳过反馈修正，只执行陀螺仪积分；
- 更新失败不修改四元数和模式；
- 不依赖 QObject，便于纯单元测试。

标准 Madgwick 公式须直接实现于 `madgwick_filter.cpp`，不得引入无来源的第三方二进制库。

### 11.3 `SixImuSolver`

```cpp
struct EulerAngles {
    double rollDegrees = 0.0;
    double pitchDegrees = 0.0;
    double yawDegrees = 0.0;
};

struct SensorPose {
    SensorId sensorId = SensorId::Wrist;
    QQuaternion worldOrientation;
    QQuaternion relativeOrientation;
    EulerAngles relativeEuler;
    FusionMode mode = FusionMode::Invalid;
    bool valid = false;
    bool calibrated = false;
    bool sourceAllZero = false;
    quint8 sequence = 0;
    qint64 updatedMonotonicNs = 0;
    QString status;
};

struct SixImuSnapshot {
    quint8 sequence = 0;
    std::array<ImuFrame, 6> rawFrames;
    std::array<SensorPose, 6> poses;
    qint64 updatedMonotonicNs = 0;
};

class SixImuSolver final : public QObject {
    Q_OBJECT
public:
    explicit SixImuSolver(QObject *parent = nullptr);
    SolverSettings settings() const;
    void applySettings(const SolverSettings &settings);
    void processCompleteGroup(const ImuSampleGroup &group);
    bool calibrateZero(QString *errorMessage = nullptr);
    void clearCalibration();
    void reset();
    std::optional<SixImuSnapshot> latestSnapshot() const;
signals:
    void snapshotReady(const SixImuSnapshot &snapshot);
    void stateReset(const QString &reason);
};
```

处理流程：

1. 拒绝 `complete == false` 或缺少任意六路的组；
2. 首个完整组 `dt = 0.005`；后续按 `emittedMonotonicNs` 差值；
3. `dt` 不在 `(0, 0.1]` 时使用 `0.005` 并在姿态状态注明时间步修正；
4. 每路按设置换算：
   - `acc = raw / 32768.0 * accelerometerRangeG`；
   - `gyroDps = raw / 32768.0 * gyroscopeRangeDps`；
   - `gyroRad = gyroDps * pi / 180`；
   - `mag = raw / magnetometerDivisor`；
5. 全零帧不更新该路过滤器，保留上一姿态并标记无效；
6. 磁场关闭、非有限或模长不在 `[minNorm, maxNorm]` 时向过滤器传 `std::nullopt`；
7. 六个过滤器先在临时状态中分别更新；任一路发生非磁场退化类硬错误时，整组不提交，六路过滤器、时间戳和磁场参考均保持上一状态；
8. 六路均完成后原子提交，世界四元数取各过滤器当前值；
9. 已标定时 `relative = normalized(qZero.conjugated() * qWorld)`；未标定时 relative 等于 world，`calibrated=false`；
10. 计算 relative 的 ZYX 欧拉角；
11. 发布一个包含相同 `SEQ` 的六路快照。

`calibrateZero()` 仅当最新六路姿态全部有效时成功；成功时保存六个世界四元数为 `qZero`，下一快照相对姿态应接近单位旋转。设置更新、串口重开、演示切换和显式重置均清除零位。

- 打开串口前停止演示，重置解析器、分组器、融合器、零位和统计；

## 16. 错误处理

- 串口打开失败：状态栏和 `errorOccurred` 提供端口名与 Qt 错误文本；
- 串口运行错误：关闭端口、进入 Error，不自动切演示；
- 协议噪声、长度错和 CRC 错：只累计统计，不弹窗；
- 未知地址：统计但不加入分组；
- 不完整组：显示缺失诊断，不更新公开同步姿态；
- 全零节点：原始数据可见，姿态保留上一值并标记无效；
- 融合输入异常：单路失败，不崩溃、不传播 NaN；
- 配置非法：对话框内联提示；
- 设置写入失败：对话框关闭前由主窗口报告，保持旧配置；
- 标定条件不足：不改变已有零位；
- 所有公开操作必须幂等，不抛出未处理异常。
