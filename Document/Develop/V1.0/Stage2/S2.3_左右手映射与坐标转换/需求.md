# V1.0-S2.3：左右手映射与坐标转换需求

- 所属阶段：V1.0 阶段 2
- 前置依赖：`V1.0-S2.2` 验收通过
- 版本目标：完成左右手节点映射、四元数顺序和坐标方向验证

## 1. 目标

1. 支持左手和右手设备配置；
2. 固定六路地址、Sensor ID 和骨骼位置；
3. 明确源四元数和 SlimeVR 输出语义；
4. 支持每路固定安装旋转；
5. 用单位和单轴动作验证乘法顺序、符号和镜像。

## 3. 功能需求

### FR-1 手侧

配置只允许 Left/Right；切换时暂停姿态，重新握手和发送六路 SensorInfo，再恢复发送。握手 tracker type 左手为 `1`，右手为 `2`。

### FR-2 坐标定义

设计文档必须先明确：融合四元数表示方向、Qt 乘法语义、SlimeVR 所需方向、源/目标正轴、固定安装旋转左乘或右乘、是否共轭，以及左右手镜像由哪一层承担。不得凭视觉试错替代定义。

### FR-3 四元数边界

内部使用命名字段；网络固定 `x,y,z,w`；转换后重新验证有限值和单位范数；禁止通过欧拉角中转。

### FR-4 固定安装旋转

六路分别持有单位四元数配置，默认单位值，独立保存和回退。非法或近零配置不得应用。安装旋转不得修改融合器磁场、零偏或姿态零位状态。

### FR-5 校准边界

必须区分融合姿态零位、安装旋转、Server 校准和后续磁/陀螺校准，不得叠加多个归零掩盖坐标错误。

## 4. 验证矩阵

每路执行静止基准、源 X/Y/Z 正向约 30°、正负往返和六路依次运动。左、右手分别记录预期目标轴、方向、实际结果和结论。硬件缺少某一侧时，软件确定性测试可以先通过，但真实侧验证必须列为阶段退出项。

## 5. 自动测试

覆盖左右位置映射、tracker type、手侧切换 ID 不变、单位和 90° X/Y/Z、安装旋转乘法顺序、六套配置独立保存、非法配置回退，以及重新注册先于姿态恢复。

## 6. 交付物

- 左右手配置；
- 节点映射；
- 坐标适配器和安装旋转配置；
- 坐标系设计文档；
- 自动测试；
- 左右手动作验证记录；
- 问题清单和完成报告。

## 7. 验收标准

1. 左右手注册类型和节点正确；
2. 地址、ID 和节点一一对应；
3. 单位与单轴旋转测试通过；
4. 每路安装旋转独立持久化；
5. 六路动作无串路；
6. 左右手正向动作符合验证表；
7. 重启后行为一致。
