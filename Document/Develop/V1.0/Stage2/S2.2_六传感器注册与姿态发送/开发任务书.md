## 3. 固定接口

```cpp
struct SlimeVrSensorDescriptor {
    SensorId sourceId;
    quint8 sensorId;
    quint8 sensorPosition;
};

std::array<SlimeVrSensorDescriptor, 6> leftHandSensorMapping();

struct SlimeVrPoseSample {
    quint8 sensorId;
    QQuaternion orientation;
    qint64 updatedMonotonicNs;
    bool valid;
};

class SlimeVrPoseAdapter {
public:
    std::array<SlimeVrPoseSample, 6> adapt(const SixImuSnapshot &) const;
};

class SlimeVrPoseSender final : public QObject {
    Q_OBJECT
public:
    void submitSnapshot(const SixImuSnapshot &);
    void start();
    void stop();
};
```

发送器只保存最新快照。不得使用无界 queue。

## 4. 协议扩展

- `SensorInfo=15`，字段按当前固件顺序显式编码；
- `RotationData=17`，字段为 `sensorId:u8`、`dataType:u8`、`x/y/z/w:be-f32`、`accuracy:u8`；
- 普通包均为 4 字节类型 + 8 字节包号；
- SensorInfo 未确认字段必须先关闭 `Q-S2.2-02`；
- `Q-S2.2-01` 未关闭前不得决定使用 relative 或 world orientation。

## 5. 实施顺序

1. 关闭阻断问题并固定 SensorInfo 黄金字节；
2. 实现地址/ID/位置映射测试；
3. 扩展协议编码器；
4. 实现姿态有效性和 `x,y,z,w` 适配测试；
5. 实现 50–100 Hz 设置校验和默认 75 Hz；
6. 实现 latest-only 节流发送；
7. 实现重连后先六路注册、后姿态；
8. 最小接入 MainWindow 生命周期；
9. fake server 集成测试；
10. 真实 Server 验证并写完成报告。

## 6. 必测行为

- 恰好六个 ID `0–5`；
- 每路不同四元数可按 ID 还原；
- invalid、NaN、Inf、零范数和超过 500 ms 的样本拒绝；
- 单路拒绝不影响其他路；
- 200 Hz submit、75 Hz timer 下每路发送约 75 Hz；
- 停止和断线不积压；
- 重连后 SensorInfo 全部发送完成前不发姿态。
