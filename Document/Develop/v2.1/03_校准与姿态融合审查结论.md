# 模块审查 03：校准与姿态融合

## 1. 审查范围

主要文件：

- `src/calibration/axis_remap.h`
- `src/calibration/calibration_parameters.*`

## 2. 模块结论

**结论：条件通过。**

单路姿态融合的基础数学、单位换算和保护框架没有证据表明整体方向完全错误。真正的问题是校准参数没有进入产品链、磁校准 API 没有生产调用、时间语义是近似值，以及六路相对 yaw/twist 的可观测性没有正确传达到上层置信度。

因此：

- 不建议推倒 Madgwick/VQF wrapper；
- 必须重接校准状态和时间基准；
- 必须用相同真实数据比较算法，而不是只验证四元数有限；
- 在 6D 状态下不得把长期 twist 当成高置信事实。

## 3. 已确认正确部分

### 3.1 单位换算公式

加速度：

```text
raw / 32768 * rangeG * 9.80665
```

陀螺仪：

```text
raw / 32768 * rangeDps * pi / 180
```

公式正确。未确认的是实际硬件量程及其运行时配置是否生效。

### 3.2 每路独立状态设计

CalibrationPipeline 和 FusionBank 均按六路独立保存状态，避免一个传感器直接覆盖另一路滤波器。

### 3.3 PoseGuard

PoseGuard 能：

- 拒绝 NaN/Inf/零模；
- 检查范数误差；
- 必要时归一化；
- 保持上一有效姿态；
- 通过 quaternion dot 保持时间符号连续。

这些保护应保留。

### 3.4 掌指相对公式所需输出方向

当前 Madgwick 和 VQF 的现有单轴测试支持正角速度产生正轴旋转。没有证据要求修改 `worldOrientation` 的分量顺序或整体取逆。

## 4. 已证实缺陷

## F01：校准状态没有统一进入产品融合

CalibrationPipeline 的参数和 FusionBank Channel 的参数是两份独立状态。产品初始化没有将同一配置同步给两者。

当前工作树已经修正为：只有 `magnetometerCalibrated=true` 才允许磁场进入融合。这一方向正确，但产品没有调用 `FusionBank::setCalibrationParams()`，因此实际会一直认为磁场未标定。

严重度：**Critical/High**。

## F02：磁校准 API 没有产品调用链

存在：

- collect magnetic sample；
- compute calibration；
- apply calibration；

但生产 app/UI 没有完整流程调用这些 API，也没有把结果同步给 FusionBank。

后果：

- 当前正确禁用未标定磁场时，产品长期 6D；
- 若恢复旧行为直接用未标定磁场，会把每路航向拉向不同错误方向；
- 两种状态都无法得到可信长期相对 twist。

严重度：**High**。

## F03：六路 6D 相对 yaw 不可长期观测

加速度只能稳定 roll/pitch，不能提供绝对 yaw。六颗独立 6D 滤波器的航向会受各自 gyro bias 影响并相对漂移。

即使掌指相对公式正确，以下量仍会漂移：

```text
relativeYaw = yawFinger - yawWrist
```

如果 finger longitudinal axis 与漂移轴耦合，上层会把它解释为 twist、flexion 或 abduction。

这是传感器可观测性限制，不是靠后处理 clamp 能消除的问题。

严重度：**High**。

## F04：无效样本在 valid 检查前推进部分状态

FusionBank 在判断 `sample.valid` 前已经：

- 计算/更新 timestamp；
- 更新 rest detector；
- 更新 magnetic health。

CalibrationPipeline 也可能在 all-zero/invalid 路径前后更新部分时间状态。

异常样本不应改变后续有效样本的 dt、rest、mag 或 bias 历史。

严重度：**High**。

## F05：采样时间主要使用主机到达时间近似

同一串口批次内多个样本共享时间，FusionBank 使用 nominal 5 ms 回退。固定采样率时可近似，但实际采样率变化、丢组和重连时会造成积分比例错误。

严重度：**High/Medium**。

## F06：磁健康主要依赖模长

当前状态机主要检测磁场模长是否接近参考值。模长正常不代表方向可信：

- 局部金属可能旋转磁场方向但维持模长；
- 软铁影响可能随姿态变化；
- 不同传感器可能各自学习到错误参考；
- 缺少磁倾角和方向变化率检查。

严重度：**Medium**。

## F07：航向恢复限制作用对象需要重新定义

当前恢复逻辑根据最终 orientation 的 yaw 差做限速。最终 yaw 同时包含：

- 用户真实运动；
- gyro 积分；
- 磁航向修正。

应限制的是“磁校正增量”，而不是可能包含用户真实快速旋转的总 yaw。

严重度：**Medium**。

## F08：测试比较算法字段，不充分比较轨迹正确性

Madgwick/VQF 对比测试主要验证：

- valid；
- mode；
- 时间字段；
- 四元数有限和归一；
- confidence 范围。

没有系统比较：

- 同一已知轨迹的角误差；
- 静置漂移；
- 不同采样率；
- 多轴运动；
- 磁干扰恢复；
- wrist/finger 两路相对姿态误差。

严重度：**High**。

## 5. 条件性问题

### 5.1 VQF 固定 acc/mag 周期

VQF 实例以 nominal 200 Hz 构造，wrapper 只把动态 dt 传给 gyro update。若设备样本本身固定 200 Hz，仅主机批量到达，这可能是正确选择。

不能仅因函数没有接收动态 dt 就直接判定错误。V2.1 应通过 198/200/202 Hz 真实采样轨迹验证后决定是否重建 VQF 参数。

### 5.2 静止检测阈值

当前工作树放宽 gyro 和 accel 阈值，是针对实测静止偏置的合理尝试。但阈值是否适用于全部六路、佩戴状态和快速动作，需要录制数据 ROC/误判分析，不能只依据一组静置值冻结。

### 5.3 默认量程

WIT 参考资料支持 ±16g、±2000dps，但当前六路硬件寄存器配置仍需确认。默认值可用于基线，不能替代硬件证据。

## 6. 对用户症状的影响

| 症状 | 本模块贡献 |
| --- | --- |
| 巨大 twist | 6D 相对 yaw 漂移或旧版未标定磁场会放大 |
| 角度幅值错误 | 采样周期和实际 gyro range 可能造成比例误差 |
| 突然跳变 | 磁场恢复、异常样本状态污染可能贡献 |
| 反关节 | 不是本模块首要原因，主要在 basis/FK |
| 多轴串扰 | 单路 orientation 可能正确，但上层错误分解是主因 |

## 7. V2.1 修复要求

1. 统一不可变 PerSensorCalibration 配置快照；
2. CalibrationPipeline 与 FusionBank 共享同一生效状态；
3. invalid 检查前置，任何无效样本不推进状态；
4. 分离 sample time 和 receive time；
5. 接通磁采样收集、计算、保存、恢复和 UI；
6. 未标定磁场强制 6D，并把 yaw/twist 标低置信；
7. 9D 恢复只限制磁校正增量；
8. 磁健康增加方向、倾角、变化率和迟滞；
9. 用同一 raw 数据比较 Madgwick/VQF 轨迹误差；
10. 分别报告 6D 和 9D 指标；
11. 记录算法参数、sample rate 和 calibration hash。

## 8. 验收门禁

- 已知 45° 单轴轨迹方向和幅值正确；
- 三轴混合轨迹有独立 ground truth；
- 198/200/202 Hz 积分比例正确；
- 插入 invalid/all-zero 不改变后续有效轨迹；
- 六路静置偏置能够独立收敛；
- 6D 10 分钟相对 yaw 漂移有数据报告；
- 9D 校准后漂移和磁干扰恢复优于 6D 基线；
- 快速真实旋转不被 heading recovery 错误限速；
- 算法切换不改变上层四元数 frame 契约；
- 同一 raw 回放结果可重复。

## 9. 最终判断

融合层不是当前所有问题的根源，但产品级校准和磁场链尚未闭合。V2.1 应保留单路融合核心，重点修复参数接线、时间语义、invalid 状态推进和 6D/9D 可观测性表达。
