## 2. 模块结论

**结论：不通过。**

当前主线没有实现真正的逆向运动学，也没有实现能保持指尖观测一致性的受约束估计。实际行为是：

```text
一颗指尖 IMU 的三个观测角
→ 每个关节分别乘 coupling
→ 每关节独立 clamp
→ 同一角度在整条链重复累计
```

这会产生事实性错误的整链姿态。问题不仅是“近似不够准确”，而是当前 coupling 的输入语义与指尖 IMU 的物理观测语义不一致。

## 3. 能力边界

### 3.1 一颗指尖 IMU 能观测什么

一颗固定在指尖/远节的 IMU 可以提供：

- 该指段相对手掌的方向；
- 短时角速度积分；
- 在磁场可靠时的三维姿态；
- 整条手指关节累计后的末端旋转。

### 3.2 不能唯一观测什么

仅凭一颗指尖 IMU，不能唯一拆分：

- MCP flexion；
- PIP flexion；
- DIP flexion；
- MCP abduction；
- 各关节 twist；
- 指尖三维位置。

多组不同关节角可以产生相同末端方向。因此 V2.1 只能输出有明确先验的 `Estimated/Coupled` 关节角，不能标记为独立实测。

## 4. 可保留部分

### 4.1 观测与骨骼结果分层

`FingerObservation` 与 `HandBoneFrame` 分离是正确设计。上层传感器观测不应直接等同于某个模型关节角。

### 4.2 限位、锁轴和 coupling 配置化思路

每个关节保存：

- 轴；
- min/max；
- lockedAxes；
- coupling；

这一配置化方向可以保留，但字段含义和求解方式必须重定义。

### 4.3 缺帧 Held/Recovered 思路

单指失效时保持、降置信、回中和恢复限速的状态机可继续使用，但应作用于正确的关节状态。

## 5. 已证实缺陷

## K01：当前不是 IK，也没有末端误差目标

代码没有：

- 目标末端方向/姿态误差；
- Jacobian；
- 迭代优化；
- 解析逆解；
- forward predicted tip 与 observed tip 的比较。

它只是把一个 `QVector3D(flex,abd,twist)` 保存为 finger state，然后每个关节乘 coupling。

严重度：**Critical**。

## K02：总角度被重复施加到每个关节

以食指 flexion coupling 为例：

```text
metacarpal  0.35
proximal    0.55
intermediate 0.75
distal      0.90
sum         2.55
```

输入 90° 时，在未触发 clamp 前整链累计可达到 229.5°。

如果输入本来代表 distal 相对 palm 的累计旋转，则预测末端姿态应接近 90°，而不是 229.5°。

严重度：**Critical**。

## K03：主线丢失旧原型的归一化 curl 语义

旧 archived 实现先计算整链容量或传感器角范围：

```text
curl = effectiveFlexion / chainCapacity
jointAngle_i = curl * coupling_i * jointLimit_i
```

这至少明确：

- 输入是末端累计 flexion；
- 先转换为 0..1 completion；
- 再按每关节容量分配。

当前主线直接执行：

```text
jointAngle_i = observedAngle * coupling_i
```

语义发生回退。

严重度：**Critical**。

## K04：长指 metacarpal 被错误当作主要活动关节

目标 WebXR 关节链包含 metacarpal 节点，但长指主要屈曲应从 MCP/ proximal 处开始。旧 Python 参考实现对长指使用 `pivot_index=1`，即从 proximal 开始驱动。

当前配置却让 metacarpal：

- 参与 flexion；
- 承担全部 abduction；
- 参与 twist。

Index/Middle metacarpal 在掌内不应像指节一样随每次屈曲大幅旋转。

严重度：**Critical/High**。

## K05：PIP/DIP 被允许大幅 twist

当前所有长指活动关节普遍允许约 ±25° twist，并通过 coupling 逐级累计。

PIP/DIP 近似铰链，正常手指动作下不应独立产生如此大的轴向扭转。当前巨大 twist 观测会被扩散到多个指节，造成螺旋状网格。

严重度：**Critical/High**。

## K06：整链总约束不存在

当前 clamp 发生在每个关节局部：

```text
clamp(observed * coupling, jointMin, jointMax)
```

没有约束：

- 整链累计角；
- 预测末端姿态；
- 指尖到掌心距离；
- DIP/PIP 比例；
- 相邻关节的生物力学一致性；
- temporal smoothness。

严重度：**High**。

## K07：拇指没有真正独立求解模型

虽然配置有 Thumb 独立骨链，但主算法仍把同样的 flex/abd/twist 三元组乘 coupling。拇指对掌需要不同轴和多关节耦合，不能仅复用长指数据流。

严重度：**High**。

## K08：置信度只继承 IMU 最小值

FingerObservation confidence 主要取 wrist/finger confidence 的最小值。它没有考虑：

- 方向分解奇异性；
- twist 是否可观测；
- 关节解是否落在先验边界；
- 末端预测误差；
- mount/neutral 是否有效；
- solver 是否被迫饱和 clamp。

严重度：**High**。

## 6. 对用户症状的影响

| 症状 | 本模块解释 |
| --- | --- |
| 手指弯曲幅度远超真实 | coupling 和大于 1，末端总角被重复累计 |
| 掌内骨骼也弯 | metacarpal 被当成主要活动关节 |
| PIP/DIP 像螺丝一样扭 | twist 被分配到多个近似铰链关节 |
| 不同动作出现相同手型 | 没有末端误差目标，只按固定比例分配 |
| 角度看似精确但不可信 | 不可唯一观测的关节被输出为具体角度 |
| 反关节 | 错误轴符号和每关节局部 clamp 共同造成 |

## 7. V2.1 修复方案

## 7.1 长指首版模型

建议 DOF：

- metacarpal：默认固定，Ring/Pinky 如需掌弓只允许小范围独立参数；
- MCP/proximal：flexion + abduction；
- PIP/intermediate：flexion；
- DIP/distal：flexion；
- PIP/DIP twist：锁定；
- DIP 与 PIP 使用可配置关系；
- abduction 只在 MCP。

## 7.2 拇指模型

单独定义：

- CMC flexion/abduction/opposition；
- MCP flexion；
- IP flexion；
- 对掌和普通屈曲不同的先验；
- 独立动作数据集。

## 7.3 首选首版求解

优先恢复可解释的归一化 coupling：

```text
observed distal flexion
→ normalize by configured chain capacity
→ curl in [0,1]
→ distribute by joint capacity
→ forward check predicted distal orientation
```

所有分配权重必须经过归一或关节容量换算，保证 predicted distal 与 observed distal 在允许误差内一致。

## 7.4 后续优化方案

当归一化 coupling 无法处理复合动作时，使用有界最小二乘：

```text
min orientationError(predictedTip, observedTip)
  + couplingPrior
  + temporalPrior
subject to joint limits and locked axes
```

不在缺少真实数据时直接引入高维黑盒优化。

## 8. 验收门禁

- 预测 distal 姿态与观测角距离小于目标阈值；
- flexion 单调增加时，tip 到 MCP 距离单调减小；
- 零输入严格回到 bind/neutral；
- 非目标手指完全不动；
- 长指 metacarpal 不发生不合理大屈曲；
- PIP/DIP twist 始终为 0 或明确受限；
- DIP/PIP 关系满足配置；
- 所有关节不越限；
- solver 饱和时降低 confidence 并输出诊断；
- Thumb opposition 有独立测试；
- UI 明确显示 `Estimated/Coupled`，不显示为独立测量。

## 9. 最终判断

当前关节约束层必须重新定义输入语义。V2.1 不需要承诺唯一 IK，但必须保证“预测出的指尖姿态能解释 IMU 观测”，并使用可解释的解剖先验，而不是把同一角度重复乘到每个关节。
