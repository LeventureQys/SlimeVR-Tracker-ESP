# 工作包 A - 工程与模型导入

- 依赖前置：无
- 并行状态：可与工作包 B 并行
- 执行时机：设计获用户确认后的开发工作

## 目标

建立研究目录内的独立 Qt/CMake 工程，引入固定版本 Assimp，将指定 FBX 转换为设计文档第 5.1 节定义的 `RiggedModel`，并提供可诊断错误与导入测试。

## 当前状态

- 研究目录尚无 C++ 工程。
- `outputs/model_probe/Node3D_____.qml` 证明源模型包含 20 个蒙皮关节、五条分支和多个蒙皮网格。
- 源模型约 48.9 MB，外部纹理缺失，骨骼名称无解剖语义。

## 实现范围

1. 创建独立 `CMakeLists.txt`，查找 Qt6 Core/Gui/Widgets/OpenGLWidgets/Test。
2. 使用 `FetchContent` 固定 Assimp release/tag；关闭其工具、样例与测试。
3. 创建 `models/` 副本和 `models/SOURCE.md`，不得修改仓库外源 FBX。
4. 实现 `ModelImporter::load(const QString&)`。
5. 导入位置、法线、UV、索引、材质、节点层级、骨骼偏移矩阵和顶点权重。
6. 每顶点保留四个最大权重并归一化；处理零权重顶点。
7. 保留 Assimp 节点层级中影响蒙皮骨骼的父链，产生稳定父索引顺序。
8. 缺失纹理记录警告并使用默认材质，不导致模型加载失败。

## 接口与错误

严格采用 `设计文档.md` 第 5.1 节数据契约。错误包含：文件不存在、Assimp 解析失败、无网格、无骨骼、父链无效、骨骼超过 128、索引越界。接口返回结构化结果，不向 UI 抛异常。

## 测试

- 正常：研究 FBX 副本加载成功，网格非空，蒙皮骨骼数为 20。
- 权重：所有有权重顶点的权重和误差不超过 `1e-5`，影响数不超过 4。
- 层级：根父索引为 -1，其余父索引有效且先于子节点。
- 异常：不存在文件、非模型文件、无骨骼模型返回准确错误码。

## 验收标准

- 可仅构建导入库和对应测试。
- 测试实际通过并输出研究模型统计。
- Assimp 下载、源码、缓存、构建和日志均不离开研究目录。
- 不修改主工程或源 FBX。
