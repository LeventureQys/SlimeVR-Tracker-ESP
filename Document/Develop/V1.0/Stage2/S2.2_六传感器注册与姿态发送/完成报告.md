# V1.0-S2.2 完成报告

## 1. 版本目标

注册一个手套设备的六个传感器并向 SlimeVR Server 发送六路真实姿态，隔离融合与网络频率，保证单路异常不影响其他路。

## 2. 修改文件

新增（`Document/Research/手套IMU解算MVP/`）：

- `src/slimevr_sensor_mapping.h/.cpp`：六路地址/ID/左右手位置映射；
- `src/slimevr_pose_adapter.h/.cpp`：快照到六路网络样本的转换与有效性检查；
- `src/slimevr_pose_sender.h/.cpp`：SensorInfo 注册、RotationData 发送、节流与统计；
- `tests/test_slimevr_sensor_mapping.cpp`、`tests/test_slimevr_pose_sender.cpp`。

修改：

- `src/slimevr_protocol.h/.cpp`：新增 SensorInfo（8 字节载荷，config 为 u16 位域）与 RotationData（19 字节载荷）编码、通用普通包编码；
- `src/slimevr_udp_client.h/.cpp`：新增 `isConnected()`、`sendNormalPacket()`；
- `tests/fake_slimevr_server.*`：统计 SensorInfo/RotationData；
- `CMakeLists.txt`：两个新测试目标。

## 3. 关键决策（问题清单已关闭项）

- RotationData 发送 `worldOrientation`，工具零位不进网络流（Server 自做挂载校准）；
- SensorInfo 总包 20 字节，sensorType=Unknown(0)、config=0、rest=0，TPS 不发送；
- dataType=1（NORMAL）、accuracy=0；
- 连接即注册六路 + 每秒重发；过期快照（默认 500 ms）暂停姿态、不重放历史；
- 默认发送率 75 Hz，校验范围 1–200 Hz（UI 收窄 50–100）；
- 不使用 bundle。
