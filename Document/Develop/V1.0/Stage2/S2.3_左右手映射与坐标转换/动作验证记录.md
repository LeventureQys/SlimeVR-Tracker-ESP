# V1.0-S2.3 动作验证记录

## 使用说明

- 在 SlimeVR Server 完成该手部设备的挂载校准后逐行执行；
- 每路每个轴向的动作约 `30°`，观察 Server 中对应节点是否只沿预期轴、预期方向转动；
- “结论”只允许填 `通过` / `不通过`；不通过时在问题清单登记并给出公式或安装旋转修改；
- 左右手各一张表；缺失的一侧记录“未验证”并保持阶段退出项未关闭。
