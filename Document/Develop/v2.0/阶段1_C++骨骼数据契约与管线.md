# V2.0 阶段 1：C++ 骨骼数据契约与解算管线

## 1. 目标

在不依赖 UI、SlimeVR 网络和具体 FBX 导出格式的前提下，建立：

```text
SixImuSnapshot
→ HandImuFrame
→ ImuPoseMapper
→ PoseSolver
→ HandSkeletonFrame
```

## 2. 新增文件

位于 `Document/Research/手套IMU解算MVP/`：

- `src/hand_skeleton_types.h`：V2.0 独立骨骼帧契约；
- `src/hand_skeleton_pipeline.h/.cpp`：六路姿态到骨骼帧管线；
- `tests/test_hand_skeleton_pipeline.cpp`：合成骨架端到端单元测试。

阶段 0 已新增：

- `src/hand_skeleton_adapter.h/.cpp`；
- `tests/test_hand_skeleton_adapter.cpp`。

## 3. HandSkeletonFrame 契约

每帧包含：

- 原始 `sequence`；
- 单调时间戳；
- 每根骨骼名称和父索引；
- 绑定平移；
- 当前局部旋转四元数；
- 当前局部矩阵；
- 当前全局矩阵；
- 蒙皮矩阵；
- 是否触发关节限制；
- 来源状态 `Estimated/Held/Invalid`；
- 置信度；
- 五指本帧输入有效性；
- 诊断错误；
- 是否为多关节耦合估计。

该结构不暴露旧 FBX Demo 的 `PoseResult`，后续 UI、录制和导出层只依赖 V2.0 契约。

## 4. 管线行为

`HandSkeleton::Pipeline`：

1. 接收 `SkeletonBinding` 和 `RigConfig`；
2. 持有旧 C++ motion 模块的 `PoseSolver` 和 `ImuPoseMapper`；
3. 将六路世界姿态转换为掌心/五指逻辑槽位；
4. 由 `ImuPoseMapper` 计算掌指相对姿态；
5. 应用传感器安装修正；
6. 提取屈伸和张合；
7. 由 `PoseSolver` 执行关节限位与耦合；
8. 输出独立 `HandSkeletonFrame`；
9. 支持 `reset()`，用于串口重连、回放重启和时间轴重置。

## 5. 有效性语义

本阶段测试发现旧 `ImuPoseMapper::fingerValid` 表示“该手指历史上已有可保持姿态”，不等价于“本帧传感器有效”。

V2.0 `HandSkeletonFrame::fingerValid` 已改为直接表示本帧五指输入有效性：

```text
current valid = snapshot.poses[finger].valid
```

旧姿态保持行为继续保留，但通过骨骼来源和诊断表达，不再把保持态误报为当前有效数据。

## 7. 测试

新增管线测试覆盖：

- 稳定骨骼名称和父索引；
- 局部四元数单位化；
- 绑定平移保留；
- 手掌世界旋转从手指相对动作中消除；

- 时间戳倒退时保持整帧并输出诊断；
