# 工作包 C - OpenGL 渲染与交互

- 依赖前置：工作包 A、工作包 B
- 并行状态：需等待
- 执行时机：模型导入与运动核心可用后

## 目标

使用 `QOpenGLWidget` 显示蒙皮手模、骨架叠加和旋转操纵器，并实现相机控制、骨骼拾取及受约束旋转请求。

## 输入输出

- 输入：`RiggedModel`、运动模块生成的蒙皮矩阵和可编辑骨骼集合。
- 输出：选中骨骼索引、旋转增量请求、相机状态和渲染诊断。

## 实现范围

1. OpenGL 3.3 Core 上下文与着色器错误检查。
2. 为各网格创建 VAO/VBO/EBO，上传顶点与四权重数据。
3. 实现最多 128 骨骼的 GPU 线性混合蒙皮。
4. 使用纯色材质、方向光、环境光和深度测试显示模型。
5. 绘制关节点、骨骼连线、选中高亮与允许轴操纵器。
6. CPU 射线对关节球/骨骼胶囊拾取，返回最近可编辑骨骼。
7. 操纵器拖动转换为局部角度增量，交给运动模块约束后再显示。
8. 实现轨道旋转、平移、滚轮缩放、视角适配与手势优先级。

## 错误处理

着色器失败、OpenGL 版本不足、GPU 资源创建失败或骨骼数超限时返回 `RenderError`，保持 UI 存活并禁止编辑。不得静默切换到无蒙皮显示后宣称成功。

## 测试与验收

- 着色器编译和链接成功。
- 绑定姿态显示无明显爆炸顶点，手动修改关节后相应网格连续变形。
- 相机四项操作互不冲突，操纵器命中时不旋转相机。
- 拾取能稳定选中五条手指链上的可编辑骨骼，空白处不误选。
- 超限拖动停在边界，骨长和父子连接保持不变。
- 若自动 OpenGL 测试受环境限制，必须在启动测试中提供逐项人工证据。

- 不允许平移子骨骼。
