# V2.1 手指姿态解算修复计划

## 1. 文档状态

| 项目 | 内容 |
| --- | --- |
| 状态 | Draft，进入实现前需确认坐标契约与硬件动作表 |
| 目标版本 | V2.1 |
| 主工程 | `Document/Research/手套IMU解算MVP/` |
| 目标平台 | Windows、C++20、Qt 6.8.3、MSVC 2022 x64 |
| 目标硬件 | 手腕 1 路 + 五指指尖 5 路 IMU，约 200 Hz |
| 核心原则 | 先建立会失败的物理/数学测试，再修改算法；禁止通过渲染层翻轴掩盖解算错误 |

## 2. 结论与修复范围

V2.0 当前问题不是单一符号错误，而是以下环节同时失去统一契约：

```text
原始传感器坐标
→ 校准/安装坐标
→ 单路世界姿态
→ 掌指相对姿态
→ 屈伸/张合/扭转分解
→ 指尖观测到多关节约束映射
→ 递归前向运动学
→ GLB 蒙皮
```

V2.1 不继续在现有结果上追加临时符号补丁，而是重建这条链路的数学契约、测试门禁和真实硬件证据。

### 2.1 可以保留的模块

- 25 字节协议解析、CRC 和 sequence 分组；
- 串口、录制、回放数据源框架；
- `FusedImuPose`、`HandObservationFrame`、`HandSkeletonFrame` 的分层思想；
- Madgwick/VQF 封装接口和四元数有限性保护；
- GLB 网格、权重、inverse bind 导入；
- UI、录制面板和诊断框架。

### 2.2 必须重写或重新接线的模块

- runtime 配置加载与六路参数应用；
- 传感器安装坐标和解剖坐标定义；
- `orientation_decomposition`；
- 指尖总姿态到 MCP/PIP/DIP 的约束映射；
- `KinematicSkeleton` 的虚拟层级和递归 FK；
- 腕部姿态到模型根节点的坐标转换；
- 姿态、骨骼和硬件动作测试。

### 2.3 V2.1 明确不承诺

- 不宣称一颗指尖 IMU 能独立测出 MCP/PIP/DIP 的真实关节角；
- 不实现依赖指尖三维位置的位置 IK；
- 不承诺医疗级或光学动作捕捉精度；
- 不在左手链路通过前扩展完整右手产品支持；
- 不通过交换四元数分量、统一乘负号或渲染层矩阵补丁修复安装问题。

| P0-07 | High | 腕部姿态未进入模型根变换 | 模型手腕不跟随真实手腕 | 明确算法坐标到模型坐标的基变换并驱动整手根节点 |
| P1-01 | High | 当前工作树禁用未标定磁场，但生产链没有使磁标定状态生效 | 产品长期停留在六轴，指间相对 yaw/twist 长时漂移 | 接通每路磁校准、参数同步和 6D/9D 状态机 |

| P1-04 | Medium | 磁健康主要依赖模长，缺少方向、倾角和一致性检测 | 金属干扰可能产生错误航向 | 增加方向/倾角/变化率与跨通道诊断 |

## 4. V2.1 冻结坐标契约

坐标契约必须在任何算法修改前写入代码注释、设计文档和单元测试。禁止继续使用含义不明的 `orientation`、`mount`、`relative`。

### 4.1 坐标系符号

| 符号 | 含义 |
| --- | --- |
| `W` | 融合世界坐标 |
| `S_w` | 手腕 IMU 传感器坐标 |
| `S_i` | 第 i 根手指 IMU 传感器坐标 |
| `P` | 手掌解剖坐标 |
| `F_i` | 第 i 根手指被观测指段的解剖坐标，首版按指尖/远节定义 |
| `M` | GLB 模型坐标 |
| `J_k` | 第 k 个模型关节局部坐标 |

统一采用 Hamilton `wxyz` 主动旋转：

```text
q_A_B：把 B 坐标中的向量旋转到 A 坐标。
```

因此融合输出统一命名为：

```text
q_W_S = worldFromSensor
```

### 4.2 安装外参

每颗 IMU 保存固定外参：

```text
q_S_A = sensorFromAnatomical
```

其中 `A` 对手腕为 `P`，对手指为 `F_i`。绝对解剖姿态为：

```text
q_W_P  = q_W_Sw * q_Sw_P
q_W_Fi = q_W_Si * q_Si_Fi
```

掌指相对姿态为：

```text
q_P_Fi = inverse(q_W_P) * q_W_Fi
```

该公式保留，不通过欧拉角相减。

### 4.3 中立姿态

V2.1 首版选择“在中立手指解剖局部坐标中表达动作增量”：

```text
q_F0_Ft = inverse(q_P_Fi_neutral) * q_P_Fi_current
```

所有 `sensorFlexionAxis/sensorAbductionAxis/sensorTwistAxis` 都必须表达在该中立解剖坐标中。

如果后续改为掌心坐标输出，必须使用不同公式并升级 schema；不得在同一字段中混用两种含义。

### 4.4 模型坐标

算法解剖坐标到模型坐标使用显式固定基变换：

```text
q_M_A = modelFromAnatomical
```

腕部显示增量通过共轭基变换进入模型，不在渲染器中交换分量：

```text
q_M_wristDelta = q_M_A * q_A_wristDelta * inverse(q_M_A)
```

模型关节轴必须定义在各自 `J_k` 局部坐标，传感器观测轴必须定义在 `F_i` 解剖坐标；两者是不同配置，不能共用一个含糊的 XYZ 字段。

## 5. 目标配置结构

V2.1 只保留一个运行时传感器配置真源，骨骼 rig 不再重复保存传感器 mount。

### 5.1 runtime 配置负责

- schemaVersion；
- 设备地址和传感器身份；
- 加速度/陀螺仪量程；
- acc/gyro/mag 轴重映射；
- `sensorFromAnatomicalQuaternionWxyz`；
- 陀螺仪零偏；
- 磁硬铁/软铁参数和有效状态；
- 标称采样周期；
- 左右手和配置版本；
- 校准时间、设备序列号和置信度。

### 5.2 hand rig 负责

- 模型骨名和虚拟父链；
- 传感器对应的被观测指段；
- 每指解剖观测 basis；
- 每关节局部轴、限位和锁轴；
- 长指/拇指不同的耦合或优化参数；
- 模型坐标基变换；
- 缺帧保持和恢复参数。

### 5.3 配置门禁

- 默认 asset 必须能被产品 parser 成功加载；
- `--config` 指向不同有效配置时，融合量程和 mount 输出必须发生可预测变化；
- 配置缺失、重复、非单位四元数、非正交 basis、左手/右手不匹配时启动失败；
- 禁止配置无效后静默回退到单位 mount 并继续发布姿态。

## Stage 2：重写掌指相对姿态与方向分解

### 目标

输出有明确几何含义、可往返、可限位的 flexion/abduction/twist。

### 任务

1. 保留 `inverse(q_W_P) * q_W_F` 掌指相对公式；
2. 按第 4 节契约计算中立局部增量；
3. 为每根手指加载独立解剖 basis；
4. 对 basis 做有限、单位、正交和手性校验；
5. 采用真正的 swing/twist：
   - 先沿手指纵轴提取 `q_twist`；
   - `q_swing = q_delta * inverse(q_twist)`；
   - 由 swing 后的指向量在屈伸/张合平面内求角；
6. 或在确认使用 `qFlex*qAbd*qTwist` 后，实现严格互逆的序列分解；两种实现只保留一种生产语义；
7. 对四元数采用最短弧规范或显式连续解包，确保 `q` 与 `-q` 等价；
8. 接近 180°、指向量反向、basis 退化时返回低置信/Invalid，不输出看似精确的巨大角；
9. 长指默认锁定 twist 或只输出低权重短时 twist；未完成 9D 标定时不得把长时 twist 标为高置信；
10. 拇指使用独立 basis、限位和对掌模型。

### 建议接口

```cpp
struct FingerAnatomicalBasis {
    QVector3D flexionAxis;
    QVector3D abductionAxis;
    QVector3D longitudinalAxis;
};

struct FingerPoseComponents {
    float flexionDegrees;
    float abductionDegrees;
    float twistDegrees;
    float confidence;
    bool twistObservable;
    bool valid;
};
```

### 完成门禁

- 限位范围内随机角往返误差小于 `0.05°`；
- `q` 与 `-q` 的三个输出误差小于 `1e-4°`；
- 纯屈伸不会产生超阈值的张合/twist；
- 混合旋转重构四元数角距离小于 `0.1°`；
- 奇异输入不会输出 NaN、Inf 或未约束的 ±180° 假角；
- 五指分别使用自己的 basis，测试能检测任意一路轴交换或符号翻转。

## Stage 3：重建指尖观测到多关节的约束求解

### 目标

明确“这是有约束估计，不是真实独立关节测量”，并保证预测末端姿态与指尖 IMU 观测一致。

### 3.1 长指首版自由度

- metacarpal 默认固定；
- MCP：flexion + abduction；
- PIP：flexion；
- DIP：flexion；
- PIP/DIP twist 默认锁定；
- DIP 与 PIP 使用可配置生物力学关系，例如 `DIP ≈ k * PIP`；
- abduction 只作用于 MCP；
- 允许小范围 MCP 轴向旋转时必须有独立配置和低权重先验。

### 3.2 拇指首版自由度

- CMC/MCP/IP 使用独立骨链；
- 屈伸、外展和对掌分别定义；
- 不复用长指 coupling；
- 对掌动作必须单独录制和验收。

### 3.3 求解方案

首版允许两种实现，必须选定一种并写入配置语义。

#### 方案 A：归一化耦合

```text
observedFlexion
→ 归一化 curl/总容量
→ jointAngle_i = curl * jointWeight_i * jointLimit_i
```

要求预测末端累计屈伸与观测角一致，禁止 coupling 和大于 1 后直接重复累计。

#### 方案 B：有界最小二乘

```text
min ||Log(inverse(qPredictedTip) * qObservedTip)||²
  + λcoupling * couplingPrior
  + λtemporal * temporalSmoothness
subject to joint limits and locked axes
```

当方案 A 无法满足复合动作误差时再进入方案 B，不在首版无数据依据地引入高复杂度优化器。

### 完成门禁

- 预测指尖姿态与输入观测的角距离满足配置阈值；
- 输入 flexion 从 0 单调增加时，指尖到 MCP 距离单调减小；
- 正常握拳不驱动长指 metacarpal 发生大幅屈曲；
- PIP/DIP 不出现明显轴向扭转；
- 任意关节不越限，锁轴始终为 0；
- 输出明确标记 `Estimated/Coupled`，UI 不显示为独立实测关节角。

## Stage 4：重写虚拟层级 FK 和腕部根变换

### 目标

让关节位置、蒙皮和覆盖骨架共享同一套递归 animated global 结果。

### 背景

目标 GLB 的 25 个关节在资产节点树中平铺在 Armature 下，不能直接把 GLB node local 当作解剖虚拟父链 local。

### 任务

1. 以模型 bind world 和虚拟 parent 计算虚拟局部绑定矩阵：

```text
L_bind(root) = B_world(root)
L_bind(i) = inverse(B_world(parent(i))) * B_world(i)
```

2. 先构造经过独立测试的整手根变换，再从 bind pose 递归重建：

```text
RootPose = composeDisplayAndWrist(displayRoot, q_M_wristDelta)
G_animated(root) = RootPose * L_bind(root) * Delta(root)
G_animated(i) = G_animated(parent(i)) * L_bind(i) * Delta(i)
```

`composeDisplayAndWrist()` 必须围绕冻结的腕部 pivot 组合显示变换和腕部旋转，其具体矩阵顺序由 bind pose 与腕部 90° 三轴 oracle 测试确定，不在实现前凭经验假定。

3. 蒙皮矩阵：

```text
Skin(i) = G_animated(i) * inverseBind(i)
```

4. 覆盖骨架位置直接取 `G_animated(i)` 的关节原点；
5. `localMatrix/globalMatrix/skinMatrix` 必须语义一致，不保留“计算 local 但 global 不使用”的双轨结果；
6. 将腕部世界增量经 `modelFromAnatomical` 基变换后作用于整手；
7. 非目标手指保持 bind 或其上一有效状态；
8. 保持当前缺帧 Held/Recovered 机制，但恢复插值作用于关节状态而非错误矩阵。

### 完成门禁

- bind pose CPU 蒙皮误差小于 `1e-4`；
- 所有骨段长度误差小于 `1e-4`；
- 父关节旋转会移动整棵子树；
- 旋转关节自身 pivot 位移小于 `1e-5`；
- 正屈曲方向朝掌心；
- 非目标手指关节点位移小于 `1e-5`；
- 腕部 90° 单轴旋转后全手刚体旋转方向正确；
- demo 和真实录制中的活动指尖位移不再为 0。

## Stage 5：修复采样时间、融合状态和磁场路径

### 目标

在手部几何链路正确后，消除角度比例误差、状态污染和长时 yaw/twist 漂移来源。

### 任务

1. 分离：
   - `sampleTimestampNs`：设备采样时刻；
   - `receivedMonotonicNs`：主机接收时刻；
2. 若硬件暂时不提供时间戳：
   - 使用 sequence 和配置采样周期重建 sample time；
   - 接收间隔只用于延迟/丢包诊断；
3. 采样率必须可配置并通过真实组率估计交叉验证；
4. 无效样本不得推进 filter、rest、mag、bias、lastTimestamp；
5. 明确 VQF gyro/acc/mag 的采样周期语义；固定率输入可使用固定系数，变率输入必须有数据依据后再改；
6. `CalibrationPipeline` 与 `FusionBank` 共享同一套已生效参数，不保留两份不同步状态；
7. 接通每路磁采样收集、硬铁/软铁求解、保存和恢复；
8. 未标定磁场保持 6D，并显示 twist/yaw 低置信；
9. 9D 恢复时限制磁航向校正量，而不是限制包含真实运动的总 yaw；
10. 磁健康增加模长、方向、倾角、变化率和迟滞；
11. 使用同一录制对比 Madgwick/VQF，不只比较“字段有效”。

### 完成门禁

- 198 Hz、200 Hz、202 Hz 合成轨迹的最终角度与真实积分比例一致；
- 串口批量大小变化不改变离线姿态结果；
- 插入无效样本不改变下一有效样本的滤波状态；
- 同一 raw 录制重复回放结果确定；
- 6D 与 9D 漂移分别记录，不混合给出单一结论；
- 磁干扰和恢复不会产生超过配置阈值的姿态瞬跳。

## Stage 6：系统集成与真实硬件动作矩阵

### 目标

用真实动作证据关闭方向、幅度、串路、漂移和重复性问题。

### 6.1 测试前硬件记录

必须记录：

- IMU 型号和固件版本；
- acc/gyro/mag 实际量程；
- 六块 PCB 轴丝印和右手坐标；
- 六颗 IMU 物理安装照片；
- 每颗 IMU 对应指段；
- 左右手；
- 采样率和串口组率；
- 校准参数版本；
- 模型与 rig SHA256。

缺少这些信息时，允许做软件回归，但不得宣称真实方向验收通过。

### 6.2 真实动作矩阵

| 编号 | 动作 | 主要验证 |
| --- | --- | --- |
| H01 | 张手静置 60 秒 | 零位、抖动、相对漂移 |
| H02 | 手掌绕三轴，手指保持不动 | 公共手掌旋转抵消 |
| H03 | 五指逐根屈伸 | 路由、正方向、非目标串路 |
| H04 | 四根长指逐根张合 | MCP abduction 和符号 |
| H05 | 拇指屈伸/外展/对掌 | 独立拇指模型 |
| H06 | 缓慢握拳/张开 10 次 | 单调性、耦合、重复性、反关节 |
| H07 | 快速握拳/张开 20 次 | 动态响应、限位、恢复 |
| H08 | 张手静置 10 分钟 | 6D/9D 漂移和温漂 |
| H09 | 靠近金属后移开 | 磁干扰退化与恢复 |
| H10 | 断连、重连、重新校准 | 生命周期和状态失效 |

### 6.3 暂定硬件验收指标

以下阈值在 Stage 0 获取基线后冻结；未冻结前不得作为完成项：

- 手掌单独运动时，各指 flex/abd 的变化 P95 不超过目标阈值；
- 单指运动时，非目标指变化 P95 不超过目标阈值；
- 同一动作 10 次的峰值和回零误差满足重复性阈值；
- 正屈曲全过程不出现指尖远离掌心的反关节阶段；
- twist 在 6D/9D 下分别报告漂移，不用 9D 指标掩盖 6D 不可观测性；
- 所有阈值同时保存 raw、fused、observation、skeleton 和视频证据。

### 任务

1. 派生录制 schema 升级为 V2，记录坐标契约和配置 hash；
2. 保留 raw.bin 向后回放能力；
3. UI 将“指尖观测角”和“估计关节角”分开显示；
4. twist 不可观测或低置信时显示状态，不显示虚假精确角度；
5. 更新架构、配置、校准和用户测试文档；
6. 更新验收报告，区分：
   - 数学合成通过；
   - 离线真实录制通过；
   - 实时硬件通过；
7. 生成新的发布目录前运行完整构建、CTest、回放指标和真实动作矩阵；
8. V2.0 发布目录保留为对照，不直接覆盖。

### 发布门禁

- 所有既有测试和 V2.1 新测试通过；
- 没有测试仅复制生产公式作为 expected；
- runtime config 端到端生效；
- compose/decompose 往返通过；
- 递归 FK 几何测试通过；
- 真实逐指方向、握拳和掌旋转矩阵通过；
- 10 分钟 6D/9D 漂移结果有独立报告；
- 文档不再把“链路能运行”写成“姿态方向正确”；
- 工作区无未确认构建产物和无关文件进入提交。

## 7. 实施依赖与并行关系

```text
Stage 0 红灯测试
  └─ Stage 1 配置/坐标契约
       ├─ Stage 2 姿态分解
       └─ Stage 4 虚拟层级 FK
            └─ Stage 3 关节约束求解
                 └─ Stage 6 真实动作验收

Stage 1
  └─ Stage 5 时间/融合/磁场
       └─ Stage 6 长时与磁场验收

Stage 2 + Stage 3 + Stage 4 + Stage 5 + Stage 6
  └─ Stage 7 发布收口
```

允许并行：

- Stage 2 数学分解与 Stage 4 FK 可在坐标契约冻结后并行；
- Stage 5 融合时间链可与 Stage 3 关节约束并行；
- 测试数据分析工具可从 Stage 0 持续建设。

禁止并行：

- 坐标契约未冻结前，不得分别修改 mount、neutral、模型轴；
- FK 未通过几何门禁前，不得以 UI 视觉效果验收 coupling；
- 真实安装信息未记录前，不得通过反复翻轴确定生产配置。

## 8. 第一批实施任务建议

第一批只处理 P0，建议按以下提交边界执行：

1. **测试提交**：加入四元数往返、符号等价、FK 子树位移、正屈曲和 config 生效红灯测试；
2. **配置提交**：修 schema、加载 runtime config、统一六路参数和 mount 真源；
3. **观测提交**：加入解剖 basis 与正确 swing/twist；
4. **FK 提交**：生成虚拟 local bind 并递归求 animated global；
5. **关节提交**：修复 metacarpal/PIP/DIP 自由度和归一化 coupling；
6. **融合提交**：分离 sample/receive time、前置 invalid 检查、接通磁校准；
7. **验收提交**：真实动作矩阵、指标报告和文档更新。

每个提交必须能够独立构建和通过当时全部测试；不把坐标、分解、FK、UI 大规模混在一个无法定位回归的提交中。

## 9. 最终完成定义

V2.1 只有同时满足以下条件才算完成：

1. 代码中能从命名直接判断每个四元数的源 frame 和目标 frame；
2. 六路量程、轴映射、安装外参和校准参数真实生效；
3. flex/abd/twist 能按约定重构原始动作姿态，奇异区安全降级；
4. 指尖观测不会被重复放大成不合理整链角；
5. 父关节旋转能通过递归 FK 正确移动子骨链；
6. 腕部姿态能正确驱动整手；
7. 长指不再出现掌骨大幅屈曲和 PIP/DIP 夸张 twist；
8. 合成、回放和真实动作三类证据全部存在；
9. 测试能够在重新引入轴反向、伪分解或非递归 FK 时稳定失败；
10. 文档明确区分指尖姿态观测、耦合估计关节角和不可观测自由度。
