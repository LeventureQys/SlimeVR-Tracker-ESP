# V1.0-S2.2 问题清单

## 1. 已关闭问题

| ID | 优先级 | 状态 | 结论与依据 |
| --- | --- | --- | --- |
| `Q-S2.2-01` | P0 | 已关闭 | RotationData 发送 `SensorPose::worldOrientation`。依据：SlimeVR Server 自身执行挂载校准（mounting reset），若再叠加工具端 `relativeOrientation` 会出现双重抵消；工具零位仅用于本地界面显示。 |
| `Q-S2.2-02` | P0 | 已关闭 | SensorInfo 总包 20 字节：12 字节普通头 + 8 字节载荷 `sensorId(u8)/state(u8)/type(u8)/config(u16 BE)/rest(u8)/position(u8)/dataType(u8)`。Server 只解析到 dataType，TPS 字段不发送；config 位域为 2 字节（固件 `static_assert(sizeof(SensorConfigBits)==2)`）。黄金字节测试：`test_slimevr_pose_sender::S01`。 |
| `Q-S2.2-03` | P1 | 已关闭 | accuracy 固定 `0`、dataType=`1`（`DATA_TYPE_NORMAL`），与固件外部融合传感器用法一致（`sendRotationData(sensorId, &fusedRotation, DATA_TYPE_NORMAL, 0)`）。 |
| `Q-S2.2-04` | P1 | 已关闭 | 进入 `Connected` 立即发送六路 SensorInfo，之后每 `1000 ms` 重发（与固件 `updateSensorState` 节奏一致）；不解析 Server ACK，重复注册无害。 |
| `Q-S2.2-05` | P1 | 已关闭 | 快照超过最大年龄（默认 `500 ms`）后暂停所有姿态发送，不发送离线 SensorInfo；Server 端自行判定离线；恢复新数据后重新注册并续发。 |
| `Q-S2.2-06` | P2 | 已关闭（延期） | 不使用 bundle 优化；六路每 tick 独立 RotationData，负载在 50–100 Hz 下足够小。 |
| `Q-S2.2-07` | P2 | 已关闭 | 默认发送率 `75 Hz`；设置校验范围 1–200 Hz，UI 层最终收窄到 50–100 Hz（S2.4）。 |
