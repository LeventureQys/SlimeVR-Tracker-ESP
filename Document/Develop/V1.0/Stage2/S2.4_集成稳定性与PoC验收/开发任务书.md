# V1.0-S2.4 开发任务书

## 1. Agent 任务

完成网络设置和诊断 UI、故障恢复、配置迁移、自动回归、真实 Server 测试和 30 分钟稳定性验收。不得增加新协议能力或算法优化。

## 2. 修改范围

允许修改阶段 2 已新增网络模块、`settings_dialog.*`、`main_window.*`、`test_main_window.cpp` 和 `CMakeLists.txt`。新增：

- `tests/test_slimevr_integration.cpp`
- `用户操作说明.md`
- `稳定性测试记录.md`
- `完成报告.md`

不得修改协议解析、Madgwick 或阶段 3 算法。

## 3. UI 契约

必须为新增控件分配稳定 objectName，至少覆盖：启用、发现模式、地址、端口、手侧、发送率、连接状态、Server、注册数、发送率、错误/拒绝/重连和最近收发时间。测试中必须能查找到这些控件。

设置继续使用注入的 `QSettings`；自动测试只使用临时 INI，禁止污染生产配置。

## 4. 实施顺序

1. 整理网络设置控件和校验；
2. 接入低频 UI 刷新；
3. 完成启动、关闭、切源、手侧切换生命周期；
4. 增加旧/坏配置回退测试；
5. 增加 fake server 集成测试；
6. 运行全量回归；
7. 执行真实 Server 测试矩阵；
8. 执行 30 分钟真实硬件长稳；
9. 关闭问题并形成完成报告。

## 5. 必测场景

客户端先启动、Server 先启动、Server 重启、地址不可达后恢复、网络禁用、串口断开恢复、演示/真实切换、左右切换、无效姿态、窗口关闭、重复启停、坏配置和旧配置。

## 6. 测试命令

```powershell
cmake --build build --config Debug
ctest --test-dir build -C Debug --output-on-failure
```

另按 `稳定性测试记录.md` 执行 30 分钟真实设备测试，记录进程内存、句柄、六路输入/发送率、CRC、缺组、拒绝、重连和错误。

## 7. 完成门禁

- 全部阶段 2 P0/P1 关闭；
- 自动测试全部通过；
- 左右手和 Server 重启真实验证通过；
- 30 分钟长稳通过；
- 用户说明、问题清单、稳定性记录和完成报告齐全；
- 阶段 1 行为可通过关闭网络输出完整回退。
