# 工作包 B - 运动约束与六路姿态

- 依赖前置：无；测试使用合成骨架
- 并行状态：可与工作包 A 并行
- 执行时机：设计获用户确认后的开发工作

## 目标

实现不依赖 OpenGL/UI 的骨架姿态核心、JSON 映射校验、人体工程学三级约束、六路 IMU 接口和确定性模拟源。

## 输入输出

- 输入：`RiggedModel::bones`、`config/hand_rig.json`、手动角度请求或 `HandImuFrame`。
- 输出：受约束的 `SkeletonPose`、每个骨骼全局矩阵、蒙皮矩阵和约束诊断状态。

## 实现范围

1. 实现配置解析和骨骼链连续性校验。
2. 保持绑定平移/缩放和父子关系，只叠加允许的局部旋转。
3. 实现逐轴限位、锁定轴和超限诊断。
4. 实现五指独立耦合曲线，把 `curl [0,1]` 映射到链内关节。
5. 实现掌心相对参考和 `inverse(qPalm) * qFinger` 相对四元数。
6. 从相对姿态提取配置定义的主要屈曲分量并映射为 `curl`。
7. 实现 `IHandPoseSource` 和 60 Hz 可重复模拟源。
8. 处理非单位、零模、无效和时间戳倒退输入。

## 关键约束

- 六路输入是六个 IMU 姿态观测，不是六个标量机械自由度。
- 一个手指 IMU 不能唯一恢复三个关节角；输出必须标识为耦合近似。
- 不实现 IK，不允许改变骨长，不把默认限位称为医学标准。
- 所有角度、轴和耦合比例来自 JSON，不写死在渲染或 UI。

## 测试

- 配置：缺骨、重复骨、链不连续、上下限反转均失败。
- 限位：边界内保持，边界外截断，锁定轴不变化。
- 耦合：`curl=0/0.5/1` 产生预期比例并再次受限。
- 四元数：掌心与手指相同得到单位相对姿态；已知旋转得到预期屈曲。
- 异常：零模、无效掌心、无效手指、乱序时间戳按设计处理且无 NaN。
- 矩阵：层级传播正确，绑定姿态蒙皮矩阵接近单位变换。

## 验收标准

- 所有核心测试无需创建 OpenGL 上下文即可运行。
- 对同一输入产生确定性结果。
- 错误信息包含 JSON 字段路径或 IMU 槽位。
- 接口与 `设计文档.md` 第 5.2、5.3 节一致。
