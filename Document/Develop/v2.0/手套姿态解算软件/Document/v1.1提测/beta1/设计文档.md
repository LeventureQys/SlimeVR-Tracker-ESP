## 3. 设计方案

### 3.1 UI 布局修复（需求 #1）

**问题根因**：`buildInterface()` 中右侧 `propertiesDock` 使用 `QVBoxLayout` 垂直堆叠多个面板，未设置最小宽度，且无滚动区域，导致小窗口下控件被截断。

**修复方案**：
1. 右侧 dock 设置 `setMinimumWidth(340)`。
2. dock 内容区包裹 `QScrollArea`，确保小窗口可滚动。
3. 左侧骨骼树 dock 设置 `setMinimumWidth(200)`。
4. 初始窗口尺寸调整为 `resize(1600, 900)`（适当加宽）。
5. 状态栏 QLabel 设置固定高度，避免被挤压。

### 3.2 3D 渲染修复（需求 #2）

**问题根因**：
- **彩色点**：`drawSkeleton()` 中 `GL_POINTS` 与 mesh 共享深度缓冲，z-fight 产生闪烁彩色点。
- **光照不正确**：fragment shader 仅有 ambient + diffuse，无 specular 高光，模型表面无光泽感。

**修复方案**：
1. **z-fight 修复**：绘制 overlay 前 `glDisable(GL_DEPTH_TEST)`，绘制后恢复。
2. **点大小调整**：将骨骼点大小从 `8.0 * dpr` 降为 `6.0 * dpr`。
3. **光照增强**：在 fragment shader 中增加 Blinn-Phong specular 项：
   ```glsl
   vec3 viewDir = normalize(-worldPosition.xyz);  // 需要传入世界坐标
   vec3 halfDir = normalize(lightDirection + viewDir);
   float specular = pow(max(dot(normal, halfDir), 0.0), 32.0) * 0.3;
   float lighting = 0.25 + 0.65 * diffuse + specular;
   ```
4. **法线传递修正**：vertex shader 中传递世界坐标到 fragment shader，用于 specular 计算。

### 3.3 录制功能（需求 #4）

**架构设计**：

```
MainWindow
  ├─ 录制按钮组（开始/暂停/停止）+ 时间标签
  │     ↓ clicked 信号
  ├─ DataRecorder（新增类）
  │     ├─ startRecording(folder) → 创建文件夹 + 打开 CSV
  │     ├─ pauseRecording()
  │     ├─ resumeRecording()
  │     ├─ stopRecording() → 关闭文件
  │     └─ recordFrame(ImuData) → 写入一行 CSV
  └─ QTimer(1s) → 更新录制时间标签
```

**DataRecorder 状态机**：
```
Idle → (start) → Recording → (pause) → Paused → (resume) → Recording
                                      ↓ (stop)                    ↓ (stop)
                                    Idle ← ← ← ← ← ← ← ← ← ← ←
```

**CSV 格式**（`imu_data.csv`）：
```
timestamp_ms,accel_x,accel_y,accel_z,gyro_x,gyro_y,gyro_z,angle_x,angle_y,angle_z,mag_x,mag_y,mag_z,battery_pct,temp_c,frame_count
```

**文件夹命名**：`recordings/rec_YYYYMMDD_HHMMSS/`

**集成方式**：
- `protocolParser_` 的 `dataUpdated` 信号同时连接到 UI 更新和 `DataRecorder::recordFrame()`。
- 录制按钮在"真实单 IMU"模式下可用，其他模式禁用。
- 录制状态显示在状态栏。

## 4. 接口契约

### 4.1 DataRecorder 类接口

```cpp
class DataRecorder : public QObject {
    Q_OBJECT
public:
    enum class State { Idle, Recording, Paused };

    explicit DataRecorder(QObject *parent = nullptr);
    ~DataRecorder();

    bool startRecording(const QString &baseDir);  // 创建子文件夹，打开 CSV
    void pauseRecording();
    void resumeRecording();
    void stopRecording();
    State state() const;
    qint64 recordingDurationMs() const;  // 实际录制时间（排除暂停）

public slots:
    void recordFrame(const handdemo::imu::ImuData &data);

signals:
    void stateChanged(handdemo::recorder::DataRecorder::State state);
    void errorOccurred(const QString &message);
};
```
