## 已达成

1. 纯 C++20/Qt6 产品，构建/运行/测试零 Python 依赖，不链接 SlimeVR 网络与遗留 six_imu_core。
2. 完整链路：协议 → 校准 → 融合（Madgwick/VQF）→ 手部观测（含调零）→ 骨骼解算 → GLB 蒙皮显示。
3. 录制/回放：raw.bin 字节保真、四类 jsonl、确定性回放（单测锁定）。
4. 单元测试 **18/18 通过**（`ctest --test-dir build-final -C Release`）。
5. 启动测试：demo / 回放 / 真实串口三种方式均 exit 0 并有截图证据。
6. 真实硬件实测：COM12（FTDI A50285BIA）≈198 组/s、0 CRC 错误；产品实时运行、真实录制（15s 2963 组）与真实回放均通过；期间修复 dt 时间戳聚合缺陷（`fusion.dt.anomaly`）。

## 已知限制（影响真实硬件验收）

| 项 | 状态 |
| --- | --- |
| 量程/轴向/六路安装方向 | 仍为默认/unknown，未用硬件资料确认 → 姿态与手指动作方向未标定 |
| 磁力计增益 | 占位 1.0 µT/LSB；磁健康仅按模长判异常；硬/软铁为轴向缩放简化 |

| 派生流 writer | 有界队列但 flush 仍在算法线程（非独立 writer 线程） |
| 30 分钟耐久 / 性能分位数 | 未执行 |
