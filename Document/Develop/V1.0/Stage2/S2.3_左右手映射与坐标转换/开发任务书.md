## 3. 接口契约

```cpp
enum class GloveSide { Left, Right };

struct SlimeVrMountingRotation {
    SensorId sensorId;
    QQuaternion rotation;
};

class SlimeVrCoordinateTransform {
public:
    QQuaternion transform(
        SensorId id,
        const QQuaternion &source,
        GloveSide side
    ) const;
};
```

确切乘法公式必须先写入 `坐标系设计.md`，并由单位、X/Y/Z 90°和安装旋转组合测试锁定。

## 4. 实施顺序

1. 从 `six_imu_solver.cpp` 推导源四元数语义；
2. 从协议和 Server 行为确定目标语义；
3. 写坐标系设计，不确定项进入问题清单；
4. 写失败的确定性测试；
5. 实现纯四元数转换；
6. 实现左右位置和 tracker type；
7. 实现六路安装旋转持久化和非法值回退；
8. 切换手侧时执行暂停→重新握手/注册→恢复；
9. 左右手逐路动作验证；
10. 完成报告冻结公式和配置。

## 5. 必测行为

- ID 不随手侧变化；
- 左右位置数值与需求表一致；
- 左 tracker type `1`，右为 `2`；
- 单位、90° X/Y/Z 和组合旋转角误差在容差内；
- 禁止欧拉角中转；
- 六套安装配置互不覆盖；
- 非有限、近零配置回退单位值；
- 手侧切换时旧侧姿态不继续发送。
