# 验收基准说明

本目录计划存放 web 端（旧版 Three.js 前端）的对照截图，作为"显示效果与 web 端保持一致"的观感基准（验收文档 4.2 节）。

## 现状与替代方案

- 2026-08 实测：本会话沙箱禁止命名管道，Chrome/Edge headless 均无法运行（exit 21），无法自动抓取 web 端截图。
- 依据验收文档 4.1/4.2 节预设的替代路径，观感比对改为：
  1. **桌面应用自身截图**（`--screenshot` 证据通道，启动测试产出）；
  2. **参数逐项对照表**（设计文档 5.6 节：相机/灯光/雾/色调/网格/材质常量 vs `web/js/viewer.js` 36–74 行，验收报告逐项记录）；
  3. **数值一致性**：移植公式单测 + 模拟数据逐帧比对（验收文档 4.1 节硬标准）。
- 用户如需人工观感比对：旧版 web 仍可运行（`启动上位机.bat` 或 `serve_app.py` + 浏览器），桌面版窗口可并排打开对照。
