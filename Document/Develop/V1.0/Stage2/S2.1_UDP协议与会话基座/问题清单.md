# V1.0-S2.1 问题清单

## 1. 使用规则

- 状态：`待确认`、`处理中`、`已关闭`、`延期`；
- 优先级：`P0` 阻断版本、`P1` 阻断功能验收、`P2` 可带限制完成、`P3` 优化；
- 开始编码前必须关闭所有标记“编码前”的 P0/P1；
- 关闭问题时填写结论、依据、影响文件和日期；
- Agent 不得自行猜测 P0/P1 的答案。

## 4. 已核实代码事实

- 普通包头：偏移 0 起 3 个零字节 + 1 字节包类型 + 8 字节大端包号（固件 `sendPacketType`/`sendPacketNumber`；Server 按 `u32 BE` 在偏移 0 读取，两者对类型 `<256` 等价）；
- 握手：类型 3、包号固定 0、字段顺序与固件 `sendTrackerDiscovery()` 一致；
- SensorInfo 载荷 8 字节（u16 配置位域），见 S2.2 问题清单；
- 生产设置标识沿用 `SlimeVRResearch/SixImuSolverQt`，网络设置使用 `slimevr/*` 键组。
