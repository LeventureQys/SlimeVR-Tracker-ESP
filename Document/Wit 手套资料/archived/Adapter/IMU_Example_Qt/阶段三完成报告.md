# IMU Example Qt v0.1.0 阶段三完成报告

## 1. 完成范围

- 创建独立 Qt 6/CMake 桌面工程，不修改仓库根构建和 Android 参考项目。
- 实现 `WT` 前缀 BLE 扫描、设备去重、单设备连接、GATT 服务发现、通知订阅和断开清理。
- 实现 `55 61`、`55 71` 20 字节流解析，支持分包、粘包、噪声和半帧头恢复。
- 实现加速度、角速度、角度、磁场、电量、温度、版本、更新时间和帧计数展示。
- 实现 500 ms 磁场、电量、温度、版本轮询。
- 实现标准 Widgets 数值界面，无三维、曲线、动画或配置写操作。
- 实现明确标识的演示模式和可重复的真实 BLE 硬件诊断程序。

## 7. 已知风险

- Windows BLE 在设备刚断开后可能需要数秒释放连接。本次测试有两次快速重连失败，等待 8 秒后再次连接成功。
- v0.1.0 不包含自动重连；用户遇到连接失败时可等待数秒后重新点击连接。
- 磁场继续按原 Android 示例显示“协议值”，不臆造物理单位。
- 电量由电压分段估算，不是设备直接返回的百分比。
