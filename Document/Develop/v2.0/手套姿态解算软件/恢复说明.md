## 恢复方法（技术记录）

1. **鉴定打包器**：二进制扫描确认 PyInstaller onefile，内嵌 Python **3.10.0**（魔数 `0x0D6F`）。
2. **解包**：[pyinstxtractor](https://github.com/extremecoders-re/pyinstxtractor) + Python 3.10 嵌入式环境解出 CArchive 与 PYZ 归档（137 个模块）。
3. **反编译**：PyLingual（3.10 专用模型）+ Python 3.10 官方 `dis` 反汇编 + 人工重建，三方互相校验。
4. **迭代修正**：用字节码比对脚本（`co_code` 级 diff）定位重建版与原版的每处差异，逐条修正至完全一致。期间纠正了若干反编译工具常见误判：
   - `import urllib.request` 被误渲染为 `import urllib.request as urllib`（两者字节码相同但运行时行为不同，以运行时语义为准）；
   - 集合字面量 `{...}` 被误渲染为 `frozenset({...})`（编译器折叠所致）；
   - `if not A and B:` 被误渲染为 `if A and B:`（跳转指令方向还原）；
   - `while len>=2 and not(X and Y):` 被误还原为单行条件（实际是 `while` + `if 匹配: break` 嵌套）；
   - `status` 为 `@property`、三元表达式 `crc = a if cond else b` 等结构均按字节码实证还原。

## 反编译局限（如实说明）

- 字节码中**不含注释与原始空行**，恢复文件的行号布局与原稿不同（不影响任何功能）；
- 数值字面量的进制写法无法区分（如 `0xAA` 与 `170`），已按语义等价值书写；
- 未发现任何语义缺失：全部函数、字符串文案（含中文）、类型注解、默认参数均已还原并经字节码级验证。

## 运行方法

**直接双击 `启动上位机.bat` 即可**（首次运行会自动创建 `.venv` 并安装 pyserial；默认源失败时自动改用官方源 pypi.org；出错会停留在窗口显示原因）。

也可以手动执行：

```powershell
cd 源码恢复
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python .\tools\serve_app.py --port 8000
```

浏览器打开 `http://127.0.0.1:8000/web/`。

> 注意：前端 Three.js 通过 unpkg CDN 加载（0.160.0），这是原项目设计；完全离线场景按 `web/vendor/README.md` 镜像。

## 交互协议速查（供后续维护参考）

- 串口默认波特率 921600；姿态帧协议：`AA 55 | node_id | sequence(u16 LE) | 6×float32 LE | CRC16-Modbus(u16 LE)`，共 31 字节；节点 0x50 为手腕（wxyz 四元数 + time_s + reserved），0x51–0x55 为五指（相对四元数 + bend_deg/sway_deg）；
- HTTP API：`/api/serial/ports|open|close|calibrate`、`/api/serial/status`、`/api/live/latest|stream`（SSE）；
- 标定命令：`AA 55 C0 01 00 00 + CRC16`；标定窗口 0.4 s，期间丢弃新帧。
